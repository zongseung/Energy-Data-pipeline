# 국제유가

브렌트유와 WTI의 **시간별 시세**입니다. 발전량·SMP와 같은 시각 기준이라 연료 가격과 전력 가격을 함께 볼 때 씁니다.

{% hint style="warning" %}
**현물 고시가가 아닙니다.** Hyperliquid라는 탈중앙 거래소에서 체결된 1시간 캔들이라 원유 현물 종가와는 다른 계열입니다. 논문에 "브렌트유 가격"으로 인용하기 전에 이 출처가 목적에 맞는지 먼저 판단하세요.
{% endhint %}

## 한눈에

| 항목 | 내용 |
| --- | --- |
| 영문 이름 | `research.oil_hourly` |
| 종목 | `brent` 브렌트 5,519행 (2026-03-05부터) · `wti` WTI 6,883행 (2026-01-07부터) |
| 갱신 | 매시 5분 |
| 단위 | USD (`volume`은 거래소 거래량) |
| 시간 기준 | 한국 시간 구간 시작 |

## 이런 질문에 씁니다

* 2026년 4월 WTI 시간별 종가를 CSV로 줘.
* 브렌트와 WTI의 일별 고가와 저가를 비교해 줘.
* WTI 종가와 육지 SMP를 같은 시간대로 같이 보여줘.
* 2026년 8월 태양광 발전량, WTI 종가, SMP를 시간별로 함께 보여줘.

## 컬럼

| 컬럼 | 뜻 | 참고 |
| --- | --- | --- |
| `timestamp` | 한국 시간 **구간 시작** | `09:00`은 09:00~10:00 구간의 캔들입니다 |
| `symbol` | 종목 | `brent` 브렌트 · `wti` WTI |
| `open`, `high`, `low`, `close` | 시가, 고가, 저가, 종가 | USD |
| `volume` | 그 구간 거래량 | **이 거래소의 거래량**이며 현물 시장 거래량이 아닙니다 |
| `trades` | 그 구간 체결 건수 | |

## 알아두세요

### 브렌트와 WTI는 시작일이 다릅니다

WTI는 2026-01-07부터, 브렌트는 2026-03-05부터입니다. 원천에 그만큼만 있는 것이지 빠진 것이 아닙니다. 두 종목을 나란히 비교하려면 겹치는 기간(2026-03-05 이후)부터 보세요.

### 24시간 거래됩니다

거래소가 주말과 밤에도 열려 있어 그 시간의 캔들도 나옵니다. "일별 종가"를 만들 때 국내 장 마감 시각을 가정하지 마세요. 하루의 어느 시각을 종가로 볼지는 분석하는 사람이 정합니다.

### 발전량과 함께 볼 때는 먼저 합계를 내 달라고 하세요

발전량은 발전소별 행이라 행이 아주 많습니다. 발전량을 그대로 유가·SMP와 합치면 조회가 오래 걸립니다. "발전량을 시간별 합계로 먼저 묶은 다음 유가와 SMP를 붙여 줘"라고 질문하면 훨씬 빠르게 끝납니다.

### 적재본이 없습니다

이 자료는 수집기가 쓰는 CSV 파일을 DB가 **바로** 읽습니다. 중간에 옮기는 단계가 없어서 수집이 끝나면 곧바로 조회에 반영됩니다. 브렌트와 WTI가 한 줄에 나란히 있는 원본 모양이 필요하면 `research.oil_hourly_raw`를 보세요.
