# 전력수요와 수급

전국과 제주의 전력 **수요·공급**, 발전원별 발전량, 지역난방 **열수요**입니다. 별도 접속 없이 발전량과 함께 물어볼 수 있습니다.

## 한눈에

| 데이터 | 영문 이름 | 기간 | 갱신 | 단위 |
| --- | --- | --- | --- | --- |
| 전국 수요·공급 5분 | `research.demand_5min` | 2014-01-01 ~ 현재 | 10분마다 | MW |
| 발전원별 발전 5분 | `research.gen_mix_5min` | 2026-08-23 ~ 현재 | 5분마다 | MW |
| 제주 수요·공급 5분 | `research.jeju_supply_demand` | 2021-01-01 ~ 현재 | 10분마다 | MW |
| 제주 시간별 수요 | `research.jeju_demand_hourly` | 2021-01-01 ~ 2026-06-30 | 분기마다 | MW |
| 제주 연료원별 거래량 | `research.jeju_generation_mix` | 2024년 한 해 | 갱신 없음 | MWh |
| 지역난방 열수요 | `research.heat_demand` | 2021-01-01 ~ 2023-12-31 | 갱신 없음 | 원천 단위 |
| 열수요 지사 위치 | `research.heat_demand_location` | 지사 19곳 | 갱신 없음 | |

## 이런 질문에 씁니다

* 2025년 7월 전국 전력수요의 일별 최대값을 보여줘.
* 올해 여름 전국 공급예비율이 가장 낮았던 날은 언제야?
* 어제 발전원별 발전량을 시간대별로 보여줘.
* 2025년 제주의 태양광과 풍력 발전량이 수요에서 차지하는 비율을 알려줘.

{% hint style="info" %}
**발전량과 함께 볼 때는 기간을 좁혀 달라고 하세요.** 5분 단위 자료는 행이 아주 많아서, 기간 없이 발전량과 합치면 조회가 오래 걸리거나 실패합니다. 한 달이나 한 주처럼 범위를 정해 질문하는 것이 좋습니다.
{% endhint %}

## 전국 수요·공급 5분 (`research.demand_5min`)

전력거래소 전국 계통 수급 자료입니다.

| 컬럼 | 뜻 | 단위·값 |
| --- | --- | --- |
| `timestamp` | 원천의 기준일시 그대로 (한국 시간) | 구간 시각인지 순간 시각인지 확정하지 못해 보정하지 않았습니다 |
| `current_demand` | 현재 수요 | MW |
| `current_supply` | **공급능력** | MW. 아래 주의 참고 |
| `supply_capacity` | **그날의 최대예측수요** | MW. 아래 주의 참고 |
| `supply_reserve` | 공급예비력 | MW. 공급능력에서 현재 수요를 뺀 값과 같습니다 |
| `reserve_rate` | 공급예비율 | %. 공급예비력 ÷ 현재 수요 × 100 |
| `operation_reserve` | 운영예비력 | MW (원천 정의 문서를 확인하지 못했습니다) |
| `is_holiday` | 공휴일 여부 | `true` · `false` |
| `day_type` | 요일 구분 | 0 평일 · 1 주말 · 2 공휴일 (공휴일이 우선) |

{% hint style="danger" %}
**두 컬럼의 이름과 의미가 서로 바뀌어 있습니다.**

* `current_supply`는 이름은 "현재 공급량"이지만 실제로는 **공급능력**입니다. 현재 수요보다 항상 훨씬 큽니다(예: 105,616 대 74,850).
* `supply_capacity`는 이름은 "공급능력"이지만 실제로는 **그날의 최대예측수요**입니다. 하루 종일 같은 값으로 고정됩니다.

공급능력이 필요하면 `current_supply`를, 최대예측수요가 필요하면 `supply_capacity`를 쓰세요.
{% endhint %}

## 발전원별 발전 5분 (`research.gen_mix_5min`)

전력거래소가 발표하는 실시간 발전원별 발전량(전국 계통 기준)입니다. 2026-08-23부터 5분마다 쌓습니다. 원천이 당일 자료만 제공해서 그 이전 구간은 없습니다. 단위는 모두 MW입니다.

| 컬럼 | 뜻 | 참고 |
| --- | --- | --- |
| `timestamp` | 5분 시각 (한국 시간) | `demand_5min`과 같은 기준 |
| `solar_market` | 전력시장 참여 태양광 | 계량 기반이라 태양광 셋 중 가장 믿을 만합니다 |
| `solar_ppa` | 기업 PPA 태양광 | **전력거래소 추정치** |
| `solar_btm` | 자가소비 태양광 | **전력거래소 추정치.** 계통에 안 잡히는 자가발전을 추정한 값이라 태양광 전체 규모를 볼 때만 쓰고 정산·검증에는 쓰지 마세요 |
| `wind` | 풍력 | |
| `nuclear` | 원자력 | |
| `gas` | 가스 | |
| `coal_total` | 석탄 합계 | 유연탄과 국내탄(`coal_domestic`)의 합입니다 |
| `coal_domestic` | 국내탄 | |
| `oil` | 유류 | |
| `hydro` | 수력 | |
| `pumped` | 양수 | 양수 발전 출력입니다. 펌핑(충전)은 잡히지 않습니다 |
| `renewable_total` | 신재생 합계 | 신에너지 `renewable_new`와 재생에너지 `renewable_renew`의 합입니다 |
| `renewable_new`, `renewable_renew` | 신에너지, 재생에너지 | |
| `ess` | 에너지저장장치 | **충전 중이면 음수**입니다 |

{% hint style="warning" %}
**합계 컬럼과 세부 컬럼을 함께 더하면 두 번 세어집니다.** `coal_total`은 `coal_domestic`을 포함하고, `renewable_total`은 태양광·풍력을 포함합니다. 발전원별 합계를 낼 때는 합계 컬럼과 그 안의 세부 컬럼 중 한쪽만 쓰세요.
{% endhint %}

## 제주 수요·공급 5분 (`research.jeju_supply_demand`)

제주 계통의 실시간 수급 자료입니다. `research` 스키마에서 가장 최신까지 들어오는 자료 중 하나입니다.

| 컬럼 | 뜻 | 단위 |
| --- | --- | --- |
| `timestamp` | 제주 실시간 원천의 시각 그대로 (한국 시간). 보정 없음 | |
| `supply_mw` | 공급능력 | MW |
| `demand_mw` | 수요 | MW |
| `renewable_total_mw` | 재생에너지 합계. 태양광·풍력 외 소규모 발전이 들어갈 수 있습니다 | MW |
| `solar_mw`, `wind_mw` | 태양광, 풍력 발전량 | MW |

## 제주 시간별 수요 (`research.jeju_demand_hourly`)

| 컬럼 | 뜻 | 참고 |
| --- | --- | --- |
| `timestamp` | 한국 시간 구간 시작 | 원천의 1시부터 24시까지 표기를 0시부터 23시까지의 구간 시작으로 옮겼습니다 |
| `demand_mw` | 제주 전력수요 (MW) | 2023-09-01 이전 원천은 kWh 단위여서 MW로 환산했습니다 |
| `source` | 출처 | `datagokr` 공공데이터포털 분기 파일 · `sukub_5min` 5분 수급을 시간 평균한 값 |

공공데이터포털의 분기 파일이 원천이라 분기마다 끊겨서 들어옵니다. 분기가 끝나고 열흘쯤 뒤에 올라오므로 최신 분기가 비어 보이는 것은 정상입니다. 최근 자료나 5분 단위가 필요하면 위의 제주 수요·공급 5분을 쓰세요.

## 제주 연료원별 거래량 (`research.jeju_generation_mix`)

| 컬럼 | 뜻 | 단위·값 |
| --- | --- | --- |
| `timestamp` | 한국 시간 구간 시작 | |
| `fuel_type` | 연료원 | `lng` `oil` `solar` `wind` `renewable_other` `other` |
| `gen_mwh` | 그 한 시간의 전력거래량 | MWh |

{% hint style="warning" %}
**2024년 한 해가 전부인 자료입니다.** 원천이 연 1회 갱신인데 2025년분이 아직 없고, 이 자료 자체가 다른 파일에 통합될 예정입니다. 최신 제주 발전 구성은 제주 수요·공급 5분의 `solar_mw`, `wind_mw`를 쓰세요.

또 `fuel_type`의 값이 발전소 목록(`plants`)의 발전원 값(`solar` `thermal` `wind` 등)과 달라서 그대로 이어 붙이면 안 됩니다.
{% endhint %}

## 지역난방 열수요 (`research.heat_demand`, `research.heat_demand_location`)

지사별 시간별 열수요와 그때의 기상입니다.

{% hint style="info" %}
**끊긴 것이 아니라 이것이 전량입니다.** 19개 지사 모두 2021-01-01 ~ 2023-12-31 구간이 정확히 같은 행수(26,279행)로 들어 있습니다. 수집이 중간에 멈춘 것이 아니라 처음부터 이 3년치가 자료 전체이니, 최신 자료를 기다리지 말고 그대로 쓰세요.
{% endhint %}

| 컬럼 | 뜻 | 참고 |
| --- | --- | --- |
| `timestamp` | 한국 시간 | 원천의 시각 표기 방식을 확인하지 못해 보정하지 않았습니다 |
| `branch` | 지사 이름 | 지사 위치 표의 `name`과 같습니다 |
| `heat_demand` | 열수요 | 원천 단위 그대로이며 단위를 검증하지 못했습니다 |
| `temperature`, `temperature_chill` | 기온, 체감온도 | |
| `humidity` | 습도 | |
| `wind_direction`, `wind_speed` | 풍향, 풍속 | |
| `rain_1h`, `rain_daily` | 1시간 강수량, 일 강수량 | |

**지사 위치 (`heat_demand_location`)** 는 19곳입니다.

| 컬럼 | 뜻 |
| --- | --- |
| `name` | 지사 이름 (열수요의 `branch`와 같음) |
| `address` | 주소 |
| `latitude`, `longitude` | 위도, 경도 (검증 범위는 확인하지 못했습니다) |
