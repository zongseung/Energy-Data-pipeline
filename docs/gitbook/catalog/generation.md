# 발전소와 발전량

발전소 목록은 `research.plants`, 시간별 발전량은 `research.generation`에서 조회합니다.

발전소 **142기**, 발전량 **132계열 약 720만 행**, 기간은 **2013-01-01 \~ 어제**입니다. 발전량 단위는 **kWh**, 시각은 **한국 시간 구간 시작**입니다.

{% hint style="warning" %}
**읽기 전에 두 가지만 기억하세요.**

1. 발전량 단위는 kWh입니다. 원본 파일 헤더에 "MWh"라고 적힌 자료도 실제 값은 kWh입니다.
2. 태양광만 묻는 질문에는 `fuel_type = 'solar'` 조건을 꼭 넣으세요. 한 뷰에 7개 발전원이 섞여 있습니다.
{% endhint %}

## 이런 질문에 씁니다

* 2025년 8월 태양광 발전소별 월 발전량 합계를 보여줘.
* 남동발전 석탄화력의 2026년 월별 발전량을 알려줘.
* 발전원별로 발전소가 몇 기씩 있어?
* 제주에 있는 발전소를 지도로 보여줘.

화력 전체를 보려면 `fuel_type IN ('coal', 'combined', 'biomass')`를 쓰세요.

## 발전소 목록 — `research.plants`

발전소 한 곳(호기 단위)이 한 행입니다. 시계열이 아닙니다.

### 식별

| 컬럼           | 뜻         |
| ------------ | --------- |
| `plant_id`   | 발전소 고유 번호 |
| `plant_name` | 발전소 이름    |
| `unit_no`    | 호기 번호     |

{% hint style="info" %}
**발전소를 이어 붙일 때는 `plant_id`를 쓰세요.**

원천이 발전소 표기를 바꾸는 일이 있어서 이름은 기준이 못 됩니다. 실제로 서부발전 `화순풍력`이 `화순 풍력 발전소`로 표기가 바뀌면서 한 발전소가 두 계열로 갈라져 있었고, 2026-10-21에 하나로 합쳤습니다.
{% endhint %}

### 분류

| 컬럼          | 뜻                         |
| ----------- | ------------------------- |
| `operator`  | 사업자 (위 표 참고)              |
| `fuel_type` | 발전원 (위 표 참고)              |
| `region`    | `mainland` 육지 · `jeju` 제주 |

`region`은 육지와 제주 두 값뿐입니다. **지역을 묻는 질문에는 `sido`·`sigungu`를 쓰세요.**

SMP 데이터의 지역 값(`land`·`jeju`·`unified`)과 글자가 다릅니다. 두 자료를 함께 쓸 때는 `mainland`를 `land`로 직접 맞춰야 합니다.

### 설비와 위치

| 컬럼                | 뜻         |
| ----------------- | --------- |
| `capacity_mw`     | 정격용량 (MW) |
| `lat`, `lon`      | 위도, 경도    |
| `sido`, `sigungu` | 시도, 시군구   |
| `address`         | 주소        |

**`capacity_mw`는 142기 중 40기만 값이 있습니다.** 발전원별로 차이가 큽니다.

| 발전원    | 발전소 | 값이 있는 수 |
| ------ | --- | ------- |
| 석탄     | 12  | 12      |
| 해양소수력  | 8   | 7       |
| 연료전지   | 12  | 6       |
| 태양광    | 86  | 11      |
| 풍력     | 12  | 2       |
| LNG 복합 | 10  | 0       |

태양광은 대부분 값이 없어서 **발전량을 설비용량으로 나누는 이용률 분석은 어렵습니다.** LNG 복합(분당)은 실측 발전량이 정격을 15배 넘어 값을 비워 두었습니다 — 원천이 호기별이 아닌 것으로 보입니다.

좌표는 태양광의 경우 부지 단위 근사값입니다(대략 ±2km). 가까운 기상 관측소를 찾는 데는 충분하지만 정밀한 지번 좌표는 아닙니다. 화력·연료전지·해양소수력·풍력의 좌표는 검증하지 않았습니다.

## 시간별 발전량 — `research.generation`

발전소 한 곳의 한 시간이 한 행입니다.

| 컬럼                                                           | 뜻                                              |
| ------------------------------------------------------------ | ---------------------------------------------- |
| `plant_id`, `plant_name`, `unit_no`, `operator`, `fuel_type` | 발전소 정보 (따로 조인하지 않아도 되게 펼쳐 둔 것)                 |
| `timestamp`                                                  | 발전 시각. 한국 시간 **구간 시작** (`09:00`은 09:00\~10:00) |
| `gen_kwh`                                                    | 그 한 시간의 발전량 (**kWh**)                          |
| `is_aggregate`, `data_quality`, `hourly_valid_from`          | 발전소 목록과 같은 값                                   |

{% hint style="success" %}
**믿을 수 없는 구간은 이미 빠져 있습니다.**

`data_quality`로 한 번 더 거를 필요가 없습니다. 오히려 거르면 멀쩡한 자료까지 사라집니다.
{% endhint %}

### 발전소 수가 142기와 132계열로 다른 이유

발전량 뷰에서 **10기가 빠져 있습니다.** 시간별 값을 믿을 수 없다고 판정한 발전소입니다.

**발전소가 몇 기인지 묻는 질문은 `plants`를 봐야 합니다.** 빠진 발전소는 발전량 뷰에 나오지 않습니다. 빠진 구간도 일별 합계는 쓸 수 있는 경우가 있으니 필요하면 관리자에게 요청하세요.

## 품질 등급 (`data_quality`)

| 등급      | 발전소 | 뜻                                |
| ------- | --- | -------------------------------- |
| `정상`    | 37  | 시간별·일별 모두 쓸 수 있습니다               |
| `미검증`   | 92  | 검사를 하지 않았습니다. **"깨졌다"는 뜻이 아닙니다** |
| `시간별무효` | 11  | 시간별 분포를 쓰면 안 됩니다                 |
| `전면무효`  | 2   | 일별 합계도 믿을 수 없습니다                 |

`정상`은 **태양광 일주곡선 검사를 통과한** 발전소입니다. 하루 중 발전량의 무게중심이 11\~13시에 있고 밤에 발전이 없는지를 봅니다.

`미검증`이 92기로 가장 많은 이유는 셋입니다.

* **비태양광 전체** — 검사 방법이 태양광 전용입니다. 석탄·LNG 복합은 밤에도 돌아서 같은 기준을 쓸 수 없습니다.
* **2026-10에 새로 들어온 발전소** — 중부발전 28기와 남부발전 파일데이터 신규 21기는 아직 검사하지 않았습니다.
* **풍력 전체** — 시각이 구간 시작인지 끝인지 확정하지 못해 ±1시간 불확실합니다.

**`미검증`이라는 이유만으로 빼지 마세요.** 정상이라는 보증은 없지만 문제가 있다는 근거도 없습니다.

### 일별 합계도 쓸 수 없는 2기

`탑선태양광_1`, `탑선태양광_3` (남동)입니다. 원천이 **월 단위 값을 일수로 나눠 매일 같은 값**을 보냅니다. 발전량 뷰에서 통째로 빠져 있습니다.

### 합계 계열 — 영암태양광

영암태양광(`plant_id` 140)은 영암1차(141)와 영암2차(142)를 합친 **사업 전체 계열**입니다.

| plant\_id | 이름            | 기간                       |
| --------- | ------------- | ------------------------ |
| 140       | 영암태양광 (사업 전체) | 2019-01-01 \~ 2021-12-31 |
| 141       | 영암1차태양광       | 2022-01-01 \~ 2025-12-31 |
| 142       | 영암2차태양광       | 2022-01-01 \~ 2025-12-31 |

{% hint style="warning" %}
**`is_aggregate = false`로 거르지 마세요.**

2019\~2021년 영암 발전량이 통째로 사라집니다. 세 계열은 기간이 겹치지 않아 그대로 합산해도 이중계상되지 않습니다.

이 표시는 "나중에 1차·2차가 2019\~2021년까지 채워지면 겹치게 될 계열"이라는 뜻입니다. 그때가 되면 140을 빼야 합니다.
{% endhint %}

## 원천별로 알아둘 점

| 사업자                  | 알아둘 점                       |
| -------------------- | --------------------------- |
| `nambu`              | 2026-02까지는 파일데이터, 그 이후는 API |
| `jungbu`             | 값·시각 검증 완료. 설비용량은 비어 있음     |
| `namdong`            | 비태양광은 뷰에서 1시간 옮겨 둠          |
| `seobu` · `nambu` 풍력 | 시각 ±1시간 불확실                 |

**남부발전**은 2013-01 \~ 2026-02가 파일데이터, 2026-03부터가 API입니다. 2013-01 \~ 2015-10은 API에 아예 없어서 파일이 유일한 경로입니다.

**남동발전**의 석탄·LNG복합·연료전지·해양소수력·바이오매스는 원본이 구간 끝 표기라 뷰에서 1시간 옮겨 둡니다. 태양광과 풍력은 옮기지 않습니다.

**중부발전** 검증은 이렇게 했습니다. 값은 호기 단위로 1:1 대조되는 해양소수력으로 공공데이터와 맞췄습니다(보령 1호기 0.983, 2호기 0.992, 신보령 1호기 0.935). 시각은 같은 제주에 있는 남부발전 남제주소내 태양광과 발전 무게중심을 월별로 비교해 평균 2분 차이로 일치했습니다.

## 시각 규약

모든 `timestamp`는 **한국 시간 구간 시작**입니다. 원천은 대부분 "구간이 끝나는 시각"으로 적지만 이미 옮겨 두었으니 **다시 옮기지 마세요.**

예외는 **풍력**입니다. 원천 시각이 구간 시작인지 끝인지 확정하지 못해 보정하지 않았습니다. ±1시간 불확실한 것으로 다루세요.
