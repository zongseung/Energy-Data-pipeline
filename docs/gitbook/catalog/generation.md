# 발전소와 발전량

발전소 목록은 `research.plants`, 시간별 발전량은 `research.generation`에서 조회합니다.

|       | 발전소 목록            | 시간별 발전량               |
| ----- | ----------------- | --------------------- |
| 영문 이름 | `research.plants` | `research.generation` |
| 규모    | 142기              | 132계열 · 약 720만 행      |
| 기간    |                   | 2013-01-01 \~ 어제      |
| 단위    |                   | kWh                   |
| 시각    |                   | 한국 시간, 구간 시작          |

전국 발전사 여섯 곳의 태양광·석탄·LNG복합·풍력·연료전지·해양소수력·바이오매스 발전소를 담고 있습니다. 발전소 한 곳(호기 단위)이 한 행이고, 발전량은 발전소별 한 시간이 한 행입니다.

## 이런 질문에 씁니다

* 2025년 8월 태양광 발전소별 월 발전량 합계를 보여줘.
* 남동발전 석탄화력의 2026년 월별 발전량을 알려줘.
* 발전원별로 발전소가 몇 기씩 있어?
* 제주에 있는 발전소를 지도로 보여줘.
* 설비용량이 가장 큰 발전소 열 곳은?

## 발전소 목록 — `research.plants`

### 식별

| 컬럼           | 뜻         |
| ------------ | --------- |
| `plant_id`   | 발전소 고유 번호 |
| `plant_name` | 발전소 이름    |
| `unit_no`    | 호기 번호     |

같은 발전소에 호기가 여럿이면 호기마다 한 행입니다. 예를 들어 하동본부 태양광은 1호기부터 6호기까지 여섯 행입니다.

### 분류

| 컬럼          | 뜻                         |
| ----------- | ------------------------- |
| `operator`  | 사업자 (위 표 참고)              |
| `fuel_type` | 발전원 (위 표 참고)              |
| `region`    | `mainland` 육지 · `jeju` 제주 |

`region`은 육지와 제주 두 값뿐입니다. 지역별로 보려면 `sido`·`sigungu`를 쓰세요.

SMP 데이터의 지역 값(`land`·`jeju`·`unified`)과 글자가 다릅니다. 두 자료를 함께 볼 때는 맞춰야 합니다.

### 설비와 위치

| 컬럼                | 뜻         |
| ----------------- | --------- |
| `capacity_mw`     | 정격용량 (MW) |
| `lat`, `lon`      | 위도, 경도    |
| `sido`, `sigungu` | 시도, 시군구   |
| `address`         | 주소        |

**`capacity_mw`는 142기 중 40기만 값이 있습니다.** 발전원별로 차이가 큽니다.

| 발전원    | 발전소 | 값이 있는 수 |
| ------ | --- | ------- |
| 석탄     | 12  | 12      |
| 해양소수력  | 8   | 7       |
| 연료전지   | 12  | 6       |
| 태양광    | 86  | 11      |
| 풍력     | 12  | 2       |
| LNG 복합 | 10  | 0       |

태양광은 대부분 값이 없어서 발전량을 설비용량으로 나누는 **이용률 분석은 어렵습니다.**

좌표는 태양광의 경우 부지 단위 근사값입니다(대략 ±2km). 가까운 기상 관측소를 찾는 데는 충분하지만 정밀한 지번 좌표는 아닙니다. 그 외 발전원의 좌표는 검증하지 않았습니다.

## 시간별 발전량 — `research.generation`

| 컬럼                                                  | 뜻                                          |
| --------------------------------------------------- | ------------------------------------------ |
| `timestamp`                                         | 발전 시각. 한국 시간 구간 시작 (`09:00`은 09:00\~10:00) |
| `gen_kwh`                                           | 그 한 시간의 발전량 (kWh)                          |
| `plant_id`, `plant_name`, `unit_no`                 | 발전소 식별                                     |
| `operator`, `fuel_type`                             | 사업자, 발전원                                   |
| `data_quality`, `hourly_valid_from`, `is_aggregate` | 발전소 목록과 같은 값                               |

발전소 정보가 함께 들어 있어서 목록과 따로 이어 붙이지 않아도 됩니다.

{% hint style="success" %}
**믿을 수 없는 구간은 이미 빠져 있습니다.** 품질 등급으로 한 번 더 거를 필요가 없습니다.
{% endhint %}

발전소 목록은 142기인데 발전량은 132계열입니다. 시간별 값을 믿을 수 없다고 판정한 **10기가 발전량 뷰에서 빠져** 있습니다. 발전소가 몇 기인지 묻는 질문은 목록을 봐야 합니다.

## 품질 등급 (`data_quality`)

| 등급      | 발전소 | 뜻                          |
| ------- | --- | -------------------------- |
| `정상`    | 37  | 시간별·일별 모두 쓸 수 있습니다         |
| `미검증`   | 92  | 검사하지 않았습니다. "깨졌다"는 뜻이 아닙니다 |
| `시간별무효` | 11  | 시간별 분포를 쓰면 안 됩니다           |
| `전면무효`  | 2   | 일별 합계도 믿을 수 없습니다           |

`정상`은 태양광 일주곡선 검사를 통과한 발전소입니다. 하루 중 발전량의 무게중심이 11시에서 13시 사이에 있고 밤에 발전이 없는지를 봅니다.

`미검증`이 가장 많은 이유는 검사 방법이 태양광 전용이기 때문입니다. 석탄과 LNG 복합은 밤에도 돌아서 같은 기준을 쓸 수 없고, 풍력은 시각이 ±1시간 불확실합니다.

**`미검증`이라는 이유만으로 빼지 마세요.** 정상이라는 보증은 없지만 문제가 있다는 근거도 없습니다.

## 단위와 시각

발전량 단위는 **kWh**입니다. 원본 파일 헤더에 "MWh"라고 적힌 자료도 실제 값은 kWh입니다.

모든 시각은 **한국 시간 구간 시작**입니다. 원천은 대부분 구간이 끝나는 시각으로 적지만 이미 옮겨 두었습니다.

**풍력은 예외입니다.** 원천 시각이 구간 시작인지 끝인지 확정하지 못해 ±1시간 불확실한 것으로 다루세요.
