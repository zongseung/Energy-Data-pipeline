# 발전소와 발전량

발전소 96기의 목록(`research.plants`)과 시간별 발전량(`research.generation`)입니다. 이 데이터는 단위, 시간 기준, 품질 등급을 모르고 쓰면 답이 조용히 틀립니다. 아래 "꼭 알아두세요"를 먼저 읽으세요.

## 한눈에

| 항목    | 발전소 목록            | 시간별 발전량                  |
| ----- | ----------------- | ------------------------ |
| 영문 이름 | `research.plants` | `research.generation`    |
| 규모    | 96기               | 87기 · 3,531,334행         |
| 기간    |                   | 2013-01-01 \~ 2026-10-19 |
| 단위    |                   | **kWh**                  |
| 시간 기준 |                   | 한국 시간, 구간 시작             |

발전량 뷰가 87기인 이유는 시간별 값을 믿을 수 없는 9기를 뺐기 때문입니다. 자세한 설명은 아래에 있습니다.

## 이런 질문에 씁니다

* 2025년 8월 태양광 발전소별 월 발전량 합계를 보여줘.
* 남동발전 풍력의 2026년 월별 발전량을 알려줘.
* 발전소가 발전원별로 몇 기인지 알려줘.
* 품질 등급이 `정상`이 아닌 발전소가 어디야?

## 발전소 목록 (`research.plants`)

발전소 한 곳(호기 단위)이 한 행입니다. 시계열이 아니고, 발전량 수집기가 새 발전소를 발견하면 함께 갱신됩니다.

| 컬럼                                   | 뜻                     | 참고                                                                                                  |
| ------------------------------------ | --------------------- | --------------------------------------------------------------------------------------------------- |
| `plant_id`                           | 발전소 고유 번호             | **발전소를 이어 붙일 때는 이것을 쓰세요.** 이름이 같은 발전소가 있어 이름은 기준이 못 됩니다                                             |
| `plant_name`                         | 발전소 이름                |                                                                                                     |
| `unit_no`                            | 호기 번호                 | 이름과 함께 봐야 하나로 정해지는 경우가 있습니다                                                                         |
| `operator`                           | 사업자                   | `nambu` `namdong` `seobu` `hangyoung` `ekr` `ewp`                                                   |
| `fuel_type`                          | 발전원                   | `solar` `thermal` `wind` `fuel_cell` `hydro`                                                        |
| `region`                             | 지역                    | `mainland`(육지) · `jeju`(제주). SMP의 지역 값(`land` `jeju` `unified`)과 다르니 `mainland`를 `land`로 직접 맞춰야 합니다 |
| `capacity_mw`                        | 정격용량 (MW)             | 96기 중 46기만 값이 있고 공시값과 추정값이 섞여 있습니다                                                                  |
| `lat`, `lon`                         | 위도, 경도                | 아래 "설비용량과 좌표" 참고                                                                                    |
| `sido`, `sigungu`, `address`         | 위치                    | 시도·시군구는 좌표에서 구한 값입니다. `address`는 일부 발전소만 있습니다                                                       |
| `is_aggregate`                       | 합계 계열 여부              | 아래 "영암태양광" 참고                                                                                       |
| `data_quality`                       | 품질 등급                 | 아래 "품질 등급" 참고                                                                                       |
| `hourly_valid_from`                  | 이 날짜부터 시간별 값을 믿을 수 있음 | 비어 있으면 시간별 값을 믿을 근거가 없습니다                                                                           |
| `daily_valid_from`, `daily_valid_to` | 일별 합계를 믿을 수 있는 기간     | 시간별 값이 무효여도 일별 합계는 쓸 수 있는 경우가 있습니다                                                                  |
| `data_quality_note`                  | 등급을 정한 이유             |                                                                                                     |

## 시간별 발전량 (`research.generation`)

발전소 한 곳의 한 시간이 한 행입니다.

| 컬럼                                                           | 뜻            | 참고                                        |
| ------------------------------------------------------------ | ------------ | ----------------------------------------- |
| `plant_id`, `plant_name`, `unit_no`, `operator`, `fuel_type` | 발전소 목록과 같은 값 | 따로 이어 붙이지 않아도 되게 펼쳐 둔 것입니다                |
| `timestamp`                                                  | 발전 시각        | 한국 시간 **구간 시작**입니다. `09:00`은 09:00\~10:00 |
| `gen_kwh`                                                    | 그 한 시간의 발전량  | 단위는 **kWh**                               |
| `is_aggregate`, `data_quality`, `hourly_valid_from`          | 발전소 목록의 값    |                                           |

{% hint style="info" %}
**믿을 수 없는 구간은 이미 뺐습니다.** 그래서 `data_quality`로 한 번 더 거를 필요가 없습니다.

* `전면무효` 2기는 통째로 빠져 있습니다.
* `시간별무효` 10기 중 영흥태양광 #3 계열 3기는 `hourly_valid_from`(2025-07-01) 이전 구간만 빠져 있습니다. 믿을 수 있는 시작 날짜가 아예 없는 나머지 7기는 통째로 빠져 있습니다.

통째로 빠진 9기(2기 + 7기)가 96기와 87기의 차이입니다.

**발전소가 몇 기인지 묻는 질문은 `plants`를 봐야 합니다.** 발전량 뷰에는 빠진 발전소가 나오지 않기 때문입니다. 빠진 구간도 일별 합계는 유효할 수 있으니 필요하면 관리자에게 요청하세요.
{% endhint %}

## 꼭 알아두세요

### 1. 발전량 단위는 kWh입니다

{% hint style="danger" %}
화력·연료전지·해양소수력 원본 파일의 헤더에는 "발전량(MWh)"라고 적혀 있지만 **실제 값은 kWh**입니다. 헤더만 보고 ×1000을 하면 1000배로 부풀려집니다. 모든 발전원에서 `gen_kwh`는 예외 없이 kWh입니다.
{% endhint %}

### 2. 시간 기준

모든 `timestamp`는 한국 시간 구간 시작입니다. 원천은 대부분 "구간이 끝나는 시각"으로 적지만 이미 옮겨 두었으니 **다시 옮기지 마세요.** 단 **풍력은 예외**입니다. 원천 시각이 구간 시작인지 끝인지 확정하지 못해 보정하지 않았으니 ±1시간 불확실한 것으로 다루세요.

### 3. 품질 등급

| 등급      | 발전소 수 | 뜻                                                                                 |
| ------- | ----- | --------------------------------------------------------------------------------- |
| `정상`    | 38    | 시간별·일별 모두 쓸 수 있습니다 (태양광 일주곡선 검사 통과)                                               |
| `시간별무효` | 10    | 시간별 분포를 쓰면 안 됩니다. 일별 합계는 `daily_valid_from`\~`daily_valid_to` 안에서 쓸 수 있는 경우가 있습니다 |
| `전면무효`  | 2     | 일별 합계도 믿을 수 없습니다                                                                  |
| `미검증`   | 46    | 비태양광 전체입니다. **"깨졌다"가 아니라 "검사를 태양광만 했다"는 뜻**이라 정상이라는 보증은 아닙니다                      |

비태양광은 `미검증`이라는 이유만으로 빼지 마세요. 정상이라는 보증은 없지만 문제가 있다는 근거도 없습니다.

`시간별무효` 중에도 영흥태양광 #3 계열 3기(`plant_id` 20, 29, 32)는 **2025-07-01부터 시간별 값이 정상**입니다. 등급만 보고 통째로 빼면 그 이후 자료가 모두 사라지니, 이 날짜(`hourly_valid_from`)를 함께 보세요. 이미 발전량 뷰가 이 날짜를 반영해 둔 상태입니다.

### 4. 영암태양광은 합계 계열이지만 빼지 마세요

영암태양광(`plant_id` 140)은 영암1차(141)와 영암2차(142)를 합친 사업 전체 계열입니다. 2019년부터 2021년까지는 1차와 2차가 구분되지 않아 합계로만 있고, 2022년부터는 1차·2차로 나뉘어 있습니다.

| plant\_id | 이름            | 자료 기간                    |
| --------- | ------------- | ------------------------ |
| 140       | 영암태양광 (사업 전체) | 2019-01-01 \~ 2021-12-31 |
| 141       | 영암1차태양광       | 2022-01-01 \~ 2025-12-31 |
| 142       | 영암2차태양광       | 2022-01-01 \~ 2025-12-31 |

기간이 겹치지 않아 지금은 셋을 모두 더해도 두 번 세지 않습니다. **`is_aggregate = false`로 거르면 2019년부터 2021년까지의 영암 발전량이 통째로 사라집니다.** 이 표시는 "나중에 1차·2차가 2019년부터 2021년까지 채워지면 겹치게 될 계열"이라는 뜻입니다. 그때가 되면 140을 빼야 합니다.

### 5. 설비용량과 좌표를 쓸 때

**설비용량 (`capacity_mw`)** 은 발전원마다 값이 있는 비율이 다릅니다.

| 발전원   | 발전소 수 | 값이 있는 수 |
| ----- | ----- | ------- |
| 태양광   | 50    | 8 (16%) |
| 화력    | 24    | 24      |
| 연료전지  | 8     | 6       |
| 해양소수력 | 4     | 4       |
| 풍력    | 10    | 4       |

태양광은 대부분 값이 없어서 발전량을 설비용량으로 나누는 이용률 분석은 어렵습니다.

**좌표 (`lat`, `lon`)** 는 태양광은 부지 단위의 근사값(대략 ±2km)이라 가까운 기상 관측소를 찾는 데는 충분하지만 정밀한 지번 좌표는 아닙니다. 화력·연료전지·수력·풍력의 좌표는 검증하지 않았으니 있다고 해서 정확하다는 뜻은 아닙니다.
