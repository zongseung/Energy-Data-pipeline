# 기상 관측

**실제로 관측된 날씨**입니다. 시간별 ASOS 자료와 일 단위 AWS·ASOS 자료가 있습니다. "뭐라고 예보했나"는 [기상 예보](forecast.md)에 따로 있습니다.

{% hint style="warning" %}
**관측은 한국 시간(KST), 예보는 UTC입니다.** 두 자료를 함께 쓸 때는 시간 기준을 맞춰야 합니다. 자세한 방법은 기상 예보 페이지에 있습니다.
{% endhint %}

## 한눈에

| 데이터          | 영문 이름                    | 기간                       | 규모                 | 갱신    |
| ------------ | ------------------------ | ------------------------ | ------------------ | ----- |
| ASOS 시간별 관측  | `research.weather_asos`  | 2019-01-01 \~ 2026-10-19 | 4,898,976행 · 지점 95 | 매일    |
| AWS·ASOS 일자료 | `research.aws_obs_daily` | 2015-01-01 \~ 2026-06-15 | 377,822행 · 지점 107  | 갱신 없음 |

## 이런 질문에 씁니다

* 2025년 7월 서울의 시간별 기온과 습도를 보여줘.
* 일사량을 관측하는 지점이 어디야?
* 2025년 8월 일별 강수량이 가장 많았던 지점을 알려줘.
* 일사량 관측 지점별로 2025년 월평균 일사량을 비교해 줘.

## ASOS 시간별 관측 (`research.weather_asos`)

기상청 종관기상관측(ASOS) 지점의 시간별 관측값입니다.

| 컬럼                 | 뜻             | 단위               |
| ------------------ | ------------- | ---------------- |
| `timestamp`        | 관측 시각 (한국 시간) |                  |
| `station_name`     | 관측 지점 이름      |                  |
| `temperature`      | 기온            | ℃                |
| `humidity`         | 습도            | %                |
| `solar_radiation`  | 일사량           | MJ/m²            |
| `has_solar_sensor` | 일사를 관측하는 지점인지 | `true` · `false` |

### 일사량은 관측하는 지점이 63곳뿐입니다

95개 지점 중 일사량을 관측하는 곳은 63곳(`has_solar_sensor = true`)이고, 나머지 32곳은 `solar_radiation`이 항상 비어 있습니다. 결측이 아니라 처음부터 관측하지 않는 것입니다.

{% hint style="warning" %}
**지점을 셀 때는 `has_solar_sensor`를 쓰세요.** `solar_radiation`에 값이 있는 지점을 세면 65곳이 나옵니다. 미관측 지점인 성산·제천에 값이 0인 이상값이 1건씩 섞여 있기 때문입니다.
{% endhint %}

일사 관측 지점도 밤이거나 관측을 시작하기 전에는 값이 비어 있습니다. 관측 시작 시점은 지점마다 다르니 특정 지점을 쓰기 전에 값이 있는 기간을 먼저 확인하세요.

### 일사량의 시각은 ±1시간 불확실합니다

일사량의 시간 표기가 "구간 시작"인지 "구간 끝"인지 기상청 공식 문구를 찾지 못했습니다. 보정하지 않았고, 시각이 중요한 분석(예: 특정 시각의 일사량과 발전량을 1대1로 비교)에서는 최대 1시간의 오차를 감안하세요.

## AWS·ASOS 일자료 (`research.aws_obs_daily`)

**하루 단위**입니다. 시간별 기상이 필요하면 위의 `weather_asos`를 쓰세요. AWS(방재기상관측) 93지점과 ASOS(종관기상) 14지점이 함께 들어 있습니다.

| 컬럼                           | 뜻            | 단위                                    |
| ---------------------------- | ------------ | ------------------------------------- |
| `date`                       | 관측일 (한국 시간)  |                                       |
| `station_id`, `station_name` | 지점 번호, 이름    |                                       |
| `station_type`               | 관측망 구분       | `AWS` · `ASOS`                        |
| `ta`                         | 기온           | ℃                                     |
| `wd`, `ws`                   | 풍향, 풍속       | 도, m/s                                |
| `rn_day`                     | 일 강수량        | mm                                    |
| `rn_hr1`                     | 1시간 최다 강수량   | mm                                    |
| `hm`                         | 습도           | %                                     |
| `pa`, `ps`                   | 현지기압, 해면기압   | hPa                                   |
| `imputed`                    | 결측을 채운 항목 목록 | 쉼표로 구분 (예: `ta,hm,ps`). 비어 있으면 원본 관측값 |

{% hint style="warning" %}
**`imputed`를 먼저 확인하세요.** AWS 약 31.9만 행 중 18.7만 행(58%)에 결측을 채운 값이 들어 있습니다. 관측값 그대로가 필요하면 `imputed`가 빈 행만 쓰거나, 채운 항목을 빼고 분석하세요.
{% endhint %}

기온(`ta`)은 하루를 대표하는 값이지만 평균인지 최고·최저인지는 원천에서 확인하지 못했습니다. AWS와 ASOS는 장비와 검증 수준이 다르니, 함께 통계를 내기 전에 `station_type`으로 나눠 보세요.
