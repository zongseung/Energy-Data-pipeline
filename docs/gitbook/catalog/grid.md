# 송배전망

변전소와 송전선로의 위치, 한전 배전망의 접속 여유용량입니다. 모두 **한 시점을 찍어 둔 정적 자료**라서 "지금" 값이 필요한 질문에는 맞지 않습니다.

## 한눈에

| 데이터         | 영문 이름                  | 규모              | 기준 시점               | 출처           |
| ----------- | ---------------------- | --------------- | ------------------- | ------------ |
| 변전소 위치      | `research.substations` | 1,185곳 (17개 시도) | OSM 스냅샷             | 오픈스트리트맵(OSM) |
| 송전선로        | `research.power_lines` | 4,685개          | OSM 스냅샷             | 오픈스트리트맵(OSM) |
| 배전망 접속 여유용량 | `research.kepco_grid`  | 3,611,724행      | 2026-03-23 \~ 03-30 | 한전 분산전원 연계정보 |

OSM 자료는 **좌표**로 위치를 나타내서 지도 표시와 가까운 시설 찾기에 맞고, 한전 자료는 리·지번 **주소**로 위치를 나타내서 지역별 접속 여유용량 조회에 맞습니다.

## 이런 질문에 씁니다

* 경상남도에 있는 변전소가 몇 곳이고 전압은 어떻게 돼?
* 전라남도 고흥군의 배전선로별 접속 여유용량이 큰 곳을 알려줘.
* 시도별 송전선로 길이를 비교해 줘.
* 충청북도에 한전 자료가 있는 시·군·구가 어디야?

## 변전소 위치 (`research.substations`)

| 컬럼                | 뜻               | 참고                                                           |
| ----------------- | --------------- | ------------------------------------------------------------ |
| `name`, `name_en` | 변전소 이름 (한글, 영문) | 이름이 비어 있는 행이 있습니다                                            |
| `voltage`         | 전압 (V)          | 여러 전압이면 `;`로 이어 씁니다 (예: `154000;55000;27500`). 144곳은 비어 있습니다 |
| `sub_type`        | 변전소 종류          |                                                              |
| `operator`        | 운영 기관           |                                                              |
| `sido`            | 시도              |                                                              |
| `lon`, `lat`      | 경도, 위도          | WGS84 좌표                                                     |

{% hint style="warning" %}
**공식 전수 자료가 아닙니다.** 오픈스트리트맵 기반이라 누락, 좌표 오차, 이름이 빈 곳이 있을 수 있습니다. "이 근처에 변전소가 있나" 같은 탐색에는 쓰고, 인허가나 계통 검토처럼 공식 근거가 필요한 일에는 쓰지 마세요.
{% endhint %}

## 송전선로 (`research.power_lines`)

| 컬럼           | 뜻          | 참고                                                                 |
| ------------ | ---------- | ------------------------------------------------------------------ |
| `name`       | 선로 이름      |                                                                    |
| `power_type` | 종류         | `line` 가공 송전선 3,844 · `cable` 지중 케이블 489 · `minor_line` 소규모 선로 352 |
| `voltage`    | 전압         |                                                                    |
| `sido`       | 시도         |                                                                    |
| `length_km`  | 선로 길이 (km) | 좌표로 계산한 값입니다                                                       |

선로의 좌표(선 모양)는 제공하지 않고 시도·전압·길이만 보여 줍니다.

## 배전망 접속 여유용량 (`research.kepco_grid`)

한전이 공개한 분산전원 연계 정보를 2026-03-23 \~ 03-30에 수집한 **스냅샷**입니다. 변전소 681곳, 배전선로 3,954개가 들어 있습니다. 설비가 세 단계(변전소, 주변압기, 배전선로)로 나뉘고, 각 단계마다 아래 세 가지 값이 있습니다.

* 접속된 용량(이용 중), 설비 용량, **접속 여유용량**
* 컬럼 이름에서 `g_`가 붙은 것이 **여유용량**입니다.

| 구분   | 컬럼                                                                 | 뜻                             |
| ---- | ------------------------------------------------------------------ | ----------------------------- |
| 주소   | `addr_do` `addr_si` `addr_gu` `addr_lidong` `addr_li` `addr_jibun` | 시도, 시, 군·구, 동, 리, 지번          |
| 변전소  | `subst_nm` `subst_cd`                                              | 이름, 코드                        |
|      | `subst_pwr` `subst_capa` `g_subst_capa`                            | 접속 용량 · 설비 용량 · **여유용량** (추정) |
| 주변압기 | `mtr_no`                                                           | 주변압기 번호                       |
|      | `mtr_pwr` `mtr_capa` `g_mtr_capa`                                  | 변전소와 같은 구성                    |
| 배전선로 | `dl_nm` `dl_cd`                                                    | 선로 이름, 코드                     |
|      | `dl_pwr` `dl_capa` `g_dl_capa`                                     | 접속 용량 · 설비 용량 · **여유용량**      |
| 기타   | `vol_1` `vol_2` `vol_3`                                            | 의미를 확인하지 못했습니다                |
|      | `crawled_at`                                                       | 수집한 시각. 자료의 기준 시점으로 보세요       |

용량 단위와 항목 정의는 원천 문서를 확인하지 못했습니다. kW로 추정하지만 확정이 아니므로 값의 크기를 그대로 인용하기 전에 한 번 더 확인하세요.

{% hint style="danger" %}
**세 가지를 조심하세요.**

1. **한 행이 설비가 아니라 주소 하나입니다.** 같은 변전소·선로의 값이 주소 수만큼 반복됩니다. 설비 개수나 용량을 집계할 때는 변전소는 `subst_cd`, 선로는 `dl_nm`을 **중복 없이** 세야 합니다. 그냥 더하면 크게 부풀려집니다.
2. **행이 361만 개**라서 시도(`addr_do`)를 정하지 않고 조회하면 느립니다. 지역을 먼저 정해 주세요.
3. **선로는 `dl_nm`으로 구분하세요.** `dl_cd`는 전체에 39종뿐이라 선로를 가려내지 못합니다.
{% endhint %}

{% hint style="warning" %}
**지역에 따라 빠진 곳이 있습니다.** 시는 `addr_si`에, 군·구는 `addr_gu`에 들어가고 해당이 없는 쪽은 `-기타지역`으로 채워져 있습니다. 예를 들어 전라남도는 군 단위만 있고 나주·목포 같은 시 단위는 아예 없습니다. 특정 지역을 조회하기 전에 "그 지역에 한전 자료가 있는지"부터 확인해 달라고 하세요.
{% endhint %}
