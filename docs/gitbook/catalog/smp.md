# SMP 가격

계통한계가격 3종을 정리했습니다. 하루전시장 시간별, 제주 실시간시장 15분, 가중평균입니다.

***

### research.smp\_hourly — 하루전시장 시간별 SMP

| 항목     | 값                                                                             |
| ------ | ----------------------------------------------------------------------------- |
| 행수     | 367,224                                                                       |
| 기간     | 2001-05-01 \~ 2026-08-11                                                      |
| region | `unified`(2001-05~~2009-12, 76,008행) / `land`·`jeju`(2010-01~~현재, 각 145,584행) |
| 갱신 주기  | 매일 09:00 (전날 하루전시장 시간별 SMP)                                                   |
| 단위     | 원/kWh                                                                         |

| 컬럼          | 의미                                                 |
| ----------- | -------------------------------------------------- |
| `timestamp` | KST 구간시작 (수집 단계에서 이미 hour-ending → 구간시작 변환 완료)     |
| `region`    | `unified`(2010년 이전 단일시장) / `land`(육지) / `jeju`(제주) |
| `price`     | SMP (원/kWh)                                        |

2010-01-01 이전에는 육지·제주가 한 시장이었습니다 (`region='unified'`). 이 시기를 분석할 때 `land`/`jeju`로 필터링하면 데이터가 통째로 빠집니다.

### research.smp\_realtime\_jeju — 제주 실시간시장 15분 SMP

| 항목    | 값                        |
| ----- | ------------------------ |
| 행수    | 78,912                   |
| 기간    | 2024-03-01 \~ 2026-05-31 |
| 갱신 주기 | 매일 19:00 (전일 확정치)        |

{% hint style="warning" %}
**원천이 확정 공표를 멈췄습니다.** 2026-05-30 이후로 KPX가 확정 가격을 내지 않습니다. 수집기는 매일 정상 동작하지만 가져올 확정 데이터가 없습니다 — 우리 쪽 장애가 아닙니다.
{% endhint %}

2026-08-13에 KPX 페이지를 직접 확인한 결과입니다.

| 구분            | 범위                                  |
| ------------- | ----------------------------------- |
| KPX가 게시하는 열   | 2024-03-01 \~ 2026-08-11 (852열)     |
| 그중 확정된 열      | 2024-03-01 \~ **2026-05-30** (818열) |
| 2026-05-31 이후 | 31열 전부 "확정가격은 D+1일 18시까지 공표예정" 표시   |

우리 DB는 KPX가 확정한 마지막 날까지 이미 다 받아 뒀습니다. 원천이 재개되면 수집도 자동으로 이어집니다. 쓰기 전에 최신 시점을 확인하시려면:

```sql
SELECT max("timestamp") FROM research.smp_realtime_jeju;
```

| 컬럼             | 의미                                                  |
| -------------- | --------------------------------------------------- |
| `timestamp`    | KST 구간시작. 15분 단위(1시간=4구간)                           |
| `region`       | 항상 `jeju`                                           |
| `price`        | SMP (원/kWh). **음수 가격이 정상적으로 발생합니다** — 이상치로 걸러내지 마세요 |
| `is_confirmed` | `false`면 잠정치(이후 확정치로 갱신될 수 있음)                      |

### research.smp\_weighted\_avg — 가중평균 SMP (일/월/연)

| 항목    | 값                                                 |
| ----- | ------------------------------------------------- |
| 갱신 주기 | daily 행: 매일 09:00 / monthly·yearly 행: 매월 2일 07:00 |

| period\_type | price\_type | 행수     | 기간                       |
| ------------ | ----------- | ------ | ------------------------ |
| daily        | smp         | 15,299 | 2001-05-01 \~ 2026-08-10 |
| monthly      | smp         | 693    | 2001-04-01 \~ 2026-04-01 |
| monthly      | blmp        | 69     | 2001-04-01 \~ 2006-12-01 |
| yearly       | smp         | 66     | 2001-01-01 \~ 2025-01-01 |
| yearly       | blmp        | 6      | 2001-01-01 \~ 2006-01-01 |

| 컬럼             | 의미                                      |
| -------------- | --------------------------------------- |
| `period_type`  | `daily`/`monthly`/`yearly`              |
| `period`       | 집계 기준일 (월별이면 해당 월 1일, 연별이면 해당 연도 1월 1일) |
| `region`       | `land`/`jeju` 등                         |
| `price_type`   | `smp`(계통한계가격) / `blmp`(기저한계가격)          |
| `weighted_avg` | 가중평균 가격 (원/kWh)                         |

**함정**: `price_type='blmp'`는 **2001\~2006년, 육지(region 관련값)만 존재**합니다. 최근 데이터나 제주 BLMP를 찾으면 결과가 비는 것이 정상입니다. 결측이 아니라 그 시기 이후로 BLMP 자체가 발행되지 않습니다.
