# SMP 가격

SMP(계통한계가격)는 전력시장에서 정해지는 전력 도매가격입니다. 단위는 **원/kWh**입니다. 이 페이지에는 세 가지가 있습니다. 하루전시장 시간별 가격, 제주 실시간시장 15분 가격, 그리고 일·월·연 가중평균입니다.

## 한눈에

| 데이터          | 영문 이름                        | 기간                                  | 갱신                |
| ------------ | ---------------------------- | ----------------------------------- | ----------------- |
| 하루전시장 시간별    | `research.smp_hourly`        | 2001-05-01 \~ 2026-10-19            | 매일                |
| 제주 실시간시장 15분 | `research.smp_realtime_jeju` | 2024-03-01 \~ 2026-10-19 (중간 공백 있음) | 매일                |
| 가중평균 (일·월·연) | `research.smp_weighted_avg`  | 2001 \~ 2026-10                     | 일별은 매일, 월별·연별은 매월 |

시각은 모두 한국 시간 구간 시작입니다. `09:00`은 09:00\~10:00(15분 자료는 15분 구간)입니다. 원천의 "구간 끝" 표기는 이미 옮겨 두었으니 다시 옮기지 마세요.

## 이런 질문에 씁니다

* 2024년 하루전시장 SMP의 월별 평균을 알려줘.
* 2026년 8월 육지와 제주의 일별 SMP를 비교해 줘.
* 태양광 발전량이 많은 시간대의 SMP는 어땠어?
* 연도별 SMP 가중평균을 보여줘.

## 하루전시장 시간별 SMP (`research.smp_hourly`)

| 컬럼          | 뜻           | 참고                                     |
| ----------- | ----------- | -------------------------------------- |
| `timestamp` | 한국 시간 구간 시작 |                                        |
| `region`    | 시장 구분       | `unified` 단일시장 · `land` 육지 · `jeju` 제주 |
| `price`     | SMP (원/kWh) |                                        |

| `region`  | 기간                       | 행수      |
| --------- | ------------------------ | ------- |
| `unified` | 2001-05-01 \~ 2009-12-31 | 76,008  |
| `land`    | 2010-01-01 \~ 2026-10-19 | 147,264 |
| `jeju`    | 2010-01-01 \~ 2026-10-19 | 147,264 |

{% hint style="warning" %}
**2010년 이전은 육지와 제주가 한 시장이었습니다.** 이 시기에는 `region`이 `unified`입니다. 2009년 이전을 `land`나 `jeju`로 조회하면 결과가 비는 것이 정상입니다.
{% endhint %}

## 제주 실시간시장 15분 SMP (`research.smp_realtime_jeju`)

| 컬럼             | 뜻           | 참고                                   |
| -------------- | ----------- | ------------------------------------ |
| `timestamp`    | 한국 시간 구간 시작 | 15분 단위입니다 (한 시간에 4개)                 |
| `region`       | 시장 구분       | 항상 `jeju`                            |
| `price`        | SMP (원/kWh) | **음수 가격이 정상적으로 나옵니다.** 이상값으로 거르지 마세요 |
| `is_confirmed` | 확정치 여부      | `false`면 잠정치라 나중에 확정치로 바뀔 수 있습니다     |

{% hint style="warning" %}
**2026-06-01 \~ 2026-08-18(79일)은 비어 있습니다.** 이 기간에는 원천(전력거래소)이 확정 가격을 공표하지 않았습니다. 수집 장애가 아니고, 2026-08-19부터 다시 들어옵니다. 이 구간을 포함하는 월 평균을 낼 때는 빠진 날짜를 감안하세요.
{% endhint %}

## 가중평균 SMP (`research.smp_weighted_avg`)

일별, 월별, 연별 가중평균입니다.

| 컬럼             | 뜻               | 참고                             |
| -------------- | --------------- | ------------------------------ |
| `period_type`  | 집계 단위           | `daily` · `monthly` · `yearly` |
| `period`       | 기준 날짜           | 월별은 그 달 1일, 연별은 그 해 1월 1일      |
| `region`       | 시장 구분           | `land` · `jeju` · `unified`    |
| `price_type`   | 가격 종류           | `smp` 계통한계가격 · `blmp` 기저한계가격   |
| `weighted_avg` | 가중평균 가격 (원/kWh) |                                |

| 집계 단위     | 가격 종류  | 행수     | 기간                       |
| --------- | ------ | ------ | ------------------------ |
| `daily`   | `smp`  | 15,439 | 2001-05-01 \~ 2026-10-19 |
| `monthly` | `smp`  | 702    | 2001-04-01 \~ 2026-07-01 |
| `monthly` | `blmp` | 69     | 2001-04-01 \~ 2006-12-01 |
| `yearly`  | `smp`  | 66     | 2001-01-01 \~ 2025-01-01 |
| `yearly`  | `blmp` | 6      | 2001-01-01 \~ 2006-01-01 |

{% hint style="warning" %}
**`blmp`(기저한계가격)는 2001\~2006년 육지 값만 있습니다.** 최근 자료나 제주 `blmp`를 찾으면 결과가 비는 것이 정상입니다. 빠진 것이 아니라 그 이후로 발표되지 않습니다.
{% endhint %}
