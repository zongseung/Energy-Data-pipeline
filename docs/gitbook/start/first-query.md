# 첫 질문 해보기

[접속 준비하기](access.md)를 마쳤다면 웹 채팅에서 첫 질문을 해 봅니다. 전체 흐름은 이렇습니다.

> 질문 → AI가 조건 확인 → 조건과 SQL 표시 → 내가 승인 → 결과 표와 CSV

## 1. 로그인

받은 서비스 주소를 브라우저에서 엽니다. 처음이라면 회원가입 화면에서 이 서비스 전용 계정을 만듭니다. **이름과 이메일은 서약 폼에 적은 것과 같게** 쓰세요. 관리자가 서약한 분과 계정을 맞춰 봅니다. 이 계정은 Tailscale 키와는 별개입니다. 처음 로그인할 때 이용 안내서 창이 뜨면 읽고 동의합니다. 비밀번호는 본인만 쓰고, 잊어버렸다면 관리자에게 재설정을 요청하세요.

## 2. 데이터 연결 켜기

새 대화를 열고 입력창 근처의 도구(MCP) 메뉴에서 `energy-db`를 켭니다. `energy-db`가 보이지 않거나 도구가 `run_sql` 하나뿐이면 설정 문제이니 관리자에게 문의하세요.

## 3. 질문하기

데이터 종류, 지역, 기간, 집계 단위를 적을수록 정확합니다. 이런 질문으로 시작해 보세요.

* 2025년 8월 태양광 발전소별 월 발전량 합계를 보여줘.
* 2024년 하루전시장 SMP의 월별 평균을 알려줘.
* 서울특별시 중구 필동의 2023년 1월 단기예보에서 1시간기온을 월별 평균으로 보여줘.

빠진 조건이 있으면 AI가 되묻습니다. 예를 들어 "서울 기온 예보"라고만 하면 단기예보인지, 어느 동인지 묻습니다. 되묻는 항목에 답하면 됩니다.

## 4. 조건과 SQL을 확인하고 승인하기

조건이 갖춰지면 AI가 정리한 조건, 실행할 SQL, 승인 링크를 보여 줍니다.

1. 조건이 내 의도와 맞는지 확인합니다. 기간, 지역, 집계 단위를 봅니다.
2. 승인 링크를 브라우저에서 열고, 그 페이지에 표시된 조건과 SQL을 다시 확인한 뒤 승인 버튼을 누릅니다.
3. 채팅으로 돌아와 승인했다고 알립니다. 그러면 승인한 SQL이 한 번 실행됩니다.

승인과 실행은 SQL 계획이 나온 뒤 30분 안에 해야 합니다. 시간이 지나면 질문부터 다시 합니다.

## 5. 결과 확인

채팅에 실행된 SQL, 결과 미리보기(처음 10행), 전체 행 수가 나옵니다. 결과가 크면 **CSV 다운로드 링크**가 함께 나오니, 전체 자료가 필요하면 CSV를 받으세요. 링크는 본인만 쓰고 파일은 바로 내려받으세요. 24시간이 지난 파일은 다음 CSV를 만들 때 정리됩니다.
