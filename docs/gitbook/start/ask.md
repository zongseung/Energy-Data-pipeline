# 질문 요령

질문을 잘 쓰면 AI가 되묻는 횟수가 줄고 결과가 정확해집니다. 처음 질문하는 순서는 [첫 질문 해보기](first-query.md)에 있고, 이 페이지는 더 잘 묻는 요령과 결과를 쓰기 전에 확인할 것을 다룹니다.

## 질문에 넣을 것

아래 다섯 가지가 들어 있을수록 좋습니다.

| 넣을 것   | 예                      |
| ------ | ---------------------- |
| 데이터 종류 | 태양광 발전량, SMP, 기온 예보    |
| 대상     | 발전소 이름, 지역(시도·시군구·읍면동) |
| 기간     | 2025년 8월, 2024년 전체     |
| 값(요소)  | 1시간기온, 발전량 합계          |
| 집계 단위  | 월별 평균, 일별 합계, 원시 행     |

## 데이터별 질문 예시

| 분야    | 질문 예                                             |
| ----- | ------------------------------------------------ |
| 발전량   | 2025년 8월 태양광 발전소별 월 발전량 합계를 보여줘.                 |
| SMP   | 2024년 하루전시장 SMP의 월별 평균을 알려줘.                     |
| 전력수요  | 2025년 7월 전국 전력수요(5분 단위)의 일별 최대값을 보여줘.            |
| 국제유가  | 2026년 4월 WTI 시간별 종가를 CSV로 줘.                     |
| 기상 예보 | 서울특별시 중구 필동의 2023년 1월 단기예보에서 1시간기온을 월별 평균으로 보여줘. |

데이터마다 들어 있는 기간이 다릅니다. 질문하기 전에 [데이터 카탈로그](../04-data-catalog.md)에서 확인하세요.

## AI가 가정하거나 되물을 때

조건이 조금 모호하면 AI가 합리적으로 가정해서 먼저 조회하고, 가정한 내용을 답에 적습니다. 가정이 틀렸으면 고쳐서 말하면 됩니다. 조회 결과가 크게 달라질 만큼 조건이 빠졌을 때만 먼저 되묻습니다. 되묻는 항목에 답하면 같은 대화에서 이어집니다.

예를 들어 "서울의 기온 예보를 보여줘"라고 물으면 단기예보인지 초단기예보인지, 어느 구·동인지, 어떤 기온 요소와 기간인지 되묻습니다. 읍면동을 모르면 구까지만 답해도 서비스가 실제 읍면동 목록을 확인하고 선택지를 보여 줍니다.

## 결과를 쓰기 전에

AI가 질문을 SQL로 바꾸기 때문에 결과가 내 의도와 조금 다를 수 있습니다. 쓰기 전에 아래를 확인하세요.

* 받은 파일의 **기간, 지역, 단위, 행 수**가 질문과 맞는지 봅니다.
* 보고서나 논문에 쓸 때는 채팅에 남은 **실행된 SQL**과 [데이터 카탈로그](../04-data-catalog.md)를 기준으로 다시 검증하세요. 시간 기준(대부분 한국 시간 구간 시작, 기상 예보는 UTC)과 발전소 품질 등급처럼 데이터마다 주의할 점이 카탈로그에 정리돼 있습니다.
* 결과를 인용할 때는 [이용조건](../05-terms.md)의 인용 의무를 따르세요.

## CSV 받을 때 알아둘 것

* 채팅 미리보기는 처음 10행뿐입니다. 전체 자료는 CSV 링크로 받으세요.
* CSV에는 한 번에 최대 **30만 행**까지 담깁니다. 행 수가 30만에 이르렀다면 잘린 것이니 기간을 나눠 다시 조회하세요.
* CSV 링크에는 로그인이 없어서 링크를 아는 사람은 누구나 받을 수 있습니다. 다른 사람에게 **공유하지 말고** 받은 파일은 바로 내려받으세요.
* 24시간이 지난 파일은 다음 CSV를 만들 때 정리됩니다. 오래 쓸 자료는 내려받아 보관하세요.
* 엑셀로 열어도 한글이 깨지지 않습니다.

## 기상 예보 자료가 필요할 때

NAS에 없는 월을 요청했거나 새로 받아야 한다면 [기상 예보 수집 요청](../data/04-data-catalog/forecast-collect.md)을 보세요.

## 자주 막히는 곳

| 증상                   | 확인할 내용                                                       |
| -------------------- | ------------------------------------------------------------ |
| 서비스 주소가 열리지 않음       | 연결이 끊겼을 수 있습니다. [접속 준비하기](access.md)의 5단계로 확인하고 4단계를 다시 합니다. |
| 로그인이 안 되거나 비밀번호를 잊음  | 관리자에게 비밀번호 재설정을 요청합니다.                                       |
| `energy-db`가 보이지 않음  | 도구 메뉴에서 켰는지 확인합니다. 켜도 안 보이면 관리자에게 문의합니다.                     |
| AI가 데이터에 대해 엉뚱하게 설명함 | "데이터 설명서를 확인해서 다시 답해 줘"라고 요청합니다. 계속 틀리면 관리자에게 알려 주세요.        |
| 조회 실패 또는 빈 결과        | 조건과 SQL을 확인하고 요청한 기간·지역에 실제 자료가 있는지 봅니다.                     |
| CSV를 받을 수 없음         | 링크가 만료됐거나 잘못 복사되지 않았는지 확인합니다. 계속되면 관리자에게 문의합니다.              |
