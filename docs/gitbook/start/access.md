# 접속 준비하기

서비스는 닫힌 연구용 네트워크(Tailscale) 안에 있습니다. 이 페이지는 내 PC를 그 네트워크에 연결하는 방법이며, PC마다 한 번만 하면 됩니다.

{% hint style="info" %}
Tailscale 계정은 필요 없습니다. 구글·학교·회사 이메일로 가입하거나 로그인하지 마세요. 관리자가 보낸 1회용 키로 연결합니다.
{% endhint %}

## 준비물

* 연구에 쓸 PC (Windows 기준으로 설명합니다)
* 관리자에게 받는 세 가지: **키**(`tskey-auth-`로 시작합니다), **기기 이름**, **서비스 주소**

## 1단계. 서약하고 신청하기

[이용·보안 서약 제출하기](https://docs.google.com/forms/d/e/1FAIpQLSdFUMpwgGI4bBBjh5kUX_6Kk9SnaAqYF6XRIf2W1fwhdl3ylw/viewform)에서 성명, 소속, 연락처를 적고 동의 항목에 체크해 제출합니다. 연락처에는 관리자가 키를 보낼 수 있는 메일이나 전화번호를 적으세요. 서약 내용은 [이용조건 · 보안 서약](../05-terms.md)에 있습니다.

## 2단계. 키 받기

관리자가 서약을 확인하면 적어 둔 연락처로 키, 기기 이름, 서비스 주소를 보냅니다. 키는 한 번만 쓸 수 있고 보통 7일 안에 써야 합니다. 다른 사람에게 전달하지 마세요.

## 3단계. Tailscale 설치

[tailscale.com/download](https://tailscale.com/download)에서 운영체제에 맞는 프로그램을 설치합니다. 설치가 끝나면 **Log in 버튼은 누르지 마세요.** 그 버튼은 계정으로 로그인하는 방법이라 이 방식에는 필요 없습니다.

## 4단계. 키로 연결하기

관리자가 함께 보낸 `join-researcher.bat`을 더블클릭하고, 물어보는 대로 키와 기기 이름을 입력합니다. `.bat` 파일이 없다면 PowerShell에서 아래 명령을 실행해도 같습니다.

```powershell
& "$env:ProgramFiles\Tailscale\tailscale.exe" up --auth-key=<받은 키> --hostname=<받은 기기 이름>
```

명령 맨 앞의 `&`까지 한 줄 전체를 그대로 붙여 넣으세요. 줄 앞이 `>>`로 바뀌며 계속 다음 줄로 넘어가면 `Ctrl+C`로 취소하고 다시 붙여 넣습니다.

Linux와 Mac은 터미널에서 같은 명령을 씁니다. Mac은 설치 방식에 따라 명령 위치가 다를 수 있으니 막히면 관리자에게 문의하세요.

```bash
sudo tailscale up --auth-key=<받은 키> --hostname=<받은 기기 이름>
```

## 5단계. 연결 확인

터미널에서 `tailscale status`를 실행해 관리자 호스트가 목록에 보이면 연결된 것입니다. 이제 브라우저에서 받은 서비스 주소를 열면 로그인 화면이 나옵니다. 다음은 [첫 질문 해보기](first-query.md)입니다.

## 막혔을 때

| 증상                    | 원인                         | 해결                                    |
| --------------------- | -------------------------- | ------------------------------------- |
| 키가 거부되거나 만료됐다고 나옴     | 7일이 지났거나 이미 사용한 키, 오타      | 관리자에게 새 키를 요청합니다                      |
| 이미 다른 계정으로 로그인된 PC    | 예전에 Tailscale을 계정으로 써 본 PC | `tailscale logout`을 실행한 뒤 4단계를 다시 합니다 |
| 서비스 주소가 열리지 않음        | 연결이 끊김                     | `tailscale status`로 확인하고 4단계를 다시 합니다  |
| PC를 바꾸거나 운영체제를 다시 설치함 | 새 기기로 취급됨                  | 새 키를 요청합니다                            |
| 다른 PC에서도 쓰고 싶음        | 기기마다 키가 따로 필요함             | 관리자에게 추가 키를 요청합니다                     |

## 지켜 주세요

* 키는 한 번 쓰면 사라지지만, 쓰기 전에는 비밀번호와 같습니다. 채팅, 메일, 코드 저장소에 올리지 마세요.
* 키 하나는 기기 한 대용입니다.
* 과제가 끝나거나 연구에서 빠지면 관리자가 기기 등록을 삭제하고, 그 뒤에는 접속할 수 없습니다.
