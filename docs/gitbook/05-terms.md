# 이용조건 · 보안 서약

> **초안 고지 — 법적 검토 전.** 이 문서는 데이터 배포를 시작하기 위해 작성한 초안이며 변호사·법무 담당자의 검토를 거치지 않았습니다. 정식 계약서나 개인정보/보안 서약서를 대체하지 않습니다. 법적 구속력이 필요한 용도로 쓰기 전에 반드시 법적 검토를 받으셔야 합니다.

## 1. 목적 및 적용 범위

이 약관은 읽기전용 PostgreSQL 접속 권한(`research` 스키마) 또는 호스팅
LibreChat·MCP 서비스를 이용하는 연구원에게 적용됩니다. 데이터는 **본 과제의 연구
목적**으로만 제공되며, 아래 사항에 동의하셔야 접속 권한을 발급받을 수 있습니다.

## 2. 허용되는 사용 · 금지되는 사용

* 데이터는 **본 과제의 연구·분석 목적**에 한해 사용합니다. 과제 외 용도(다른 프로젝트, 상업적 이용, 제3자 제공 등)로 사용하지 않습니다.
* 조회 결과(원본 데이터, 원본에서 유도한 가공 데이터 포함)를 **재배포하지 않습니다.** 논문·보고서에 실을 때는 요약 통계·그래프 형태로만 포함합니다.
* 발급받은 DB role과 LibreChat 계정 자격증명을 **본인만 사용**합니다. 타인과 공유하거나 팀 계정처럼 돌려쓰지 않습니다.
* 접속 자격증명을 코드 저장소, 공개 노트북, 채팅 로그 등에 평문으로 남기지 않습니다.
* 자연어 질문에 개인정보, 비밀번호, API 키, 공개가 금지된 연구 내용을 입력하지 않습니다.

## 3. 인용 의무

이 데이터를 활용한 논문·보고서·발표 자료에는 아래와 같이 출처를 표기해야 합니다 (문구는 상황에 맞게 조정할 수 있으나, 데이터 제공처와 제공 경위가 드러나야 합니다):

> 본 연구는 \[과제명]을 통해 제공받은 전력 발전·수급 데이터(남부발전, 남동발전, 전력거래소 SMP, 기상청 ASOS 등)를 활용하였다.

공동 연구·외부 공개 논문의 경우 사전에 데이터 제공 기관과 인용 표기 방식을 협의합니다.

## 4. 감사 로그 고지

직접 SQL·로컬 stdio에서 발급받은 role로 실행하거나 호스팅 서비스의 공용
`demo_ro`로 실행하는 **모든 SQL 쿼리는 서버 측 감사 로그에 기록됩니다**
(`log_statement=all`, 접속 시각·사용자·DB명 포함). 호스팅 쿼리는 개인별 DB role이
아니라 `demo_ro`로 보일 수 있습니다. 문제가 발생하면 이 로그를 근거로 조사가
이루어질 수 있다는 점을 인지하고 사용합니다.

감사 로그 보존 기간은 별도로 정해져 있지 않습니다. 컨테이너 로그(`json-file` 드라이버)에 크기·기간 제한 없이 쌓이며, 로그 로테이션이나 만료 정책을 운영하지 않습니다.

## 5. LLM·MCP 데이터 처리 고지

호스팅 자연어 서비스를 사용하면 질문, 필요한 대화 문맥, 도구 호출 결과와 조회
미리보기가 OpenAI API로 전송될 수 있습니다. LibreChat은 계정과 대화 기록을
MongoDB에 저장하며, 현재 별도의 프로젝트 자동 삭제 기간은 설정돼 있지 않습니다.
운영 승인 workflow의 별도 MongoDB에는 질문·조건·SQL·상태가 저장되지만 조회 결과
행은 저장되지 않습니다. 전체 저장 위치와 보존 동작은
[LLM·MCP 데이터 처리와 투명성](06-llm-transparency.md)을 확인하세요.

OpenAI API 입력·출력은 기본적으로 모델 학습에 사용되지 않지만 기본
abuse-monitoring 보존은 별도입니다. 외부 전송이 허용되지 않는 내용은 LLM·MCP가
아닌 직접 SQL로 조회합니다.

## 6. 과제 종료 시 조치

* 과제가 종료되거나 연구원이 과제에서 이탈하면 **접속 권한(role)은 회수됩니다.** 회수 이후에는 더 이상 접속할 수 없습니다.
* 로컬에 내려받은 원본 데이터, 중간 산출물, 백업 사본은 과제 종료 후 **파기**합니다. 논문·보고서에 포함된 요약 통계·그래프는 파기 대상이 아닙니다.
* 관리자가 파기 확인을 요청하면 삭제를 마쳤음을 확인해 줍니다.

## 7. 데이터 한계에 대한 고지

이 데이터는 연구용으로 정리된 것이지 검증된 공식 통계가 아닙니다. 데이터 카탈로그에는 품질 등급(`data_quality`), 좌표 신뢰도, 단위·시간 규약의 함정이 정리돼 있습니다. 이를 확인하지 않고 사용한 분석 결과는 데이터 제공 측이 책임지지 않습니다. 데이터의 한계를 인지하고 사용할 책임은 연구원에게 있습니다.
