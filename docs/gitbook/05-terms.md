# 이용조건 · 보안 서약

> **초안 고지 — 법적 검토 전.** 이 문서는 데이터 배포를 시작하기 위해
> 작성한 초안이며 변호사·법무 담당자의 검토를 거치지 않았다. 정식 계약서나
> 개인정보/보안 서약서를 대체하지 않는다. 법적 구속력이 필요한 용도로 쓰기
> 전에 반드시 법적 검토를 받아야 한다.

## 1. 목적 및 적용 범위

이 약관은 Tailscale 폐쇄망을 통해 발급되는 읽기전용 PostgreSQL 접속
권한(`research` 스키마)을 이용하는 연구원에게 적용된다. 데이터는 **본
과제의 연구 목적**으로만 제공되며, 아래 사항에 동의해야 접속 권한을
발급받을 수 있다.

## 2. 허용되는 사용 · 금지되는 사용

- 데이터는 **본 과제의 연구·분석 목적**에 한해 사용한다. 과제 외 용도
  (다른 프로젝트, 상업적 이용, 제3자 제공 등)로 사용하지 않는다.
- 조회 결과(원본 데이터, 원본에서 유도한 가공 데이터 포함)를 **재배포하지
  않는다.** 논문·보고서에 실을 때는 요약 통계·그래프 형태로만 포함한다.
- 발급받은 role 자격증명(ID·비밀번호)을 **본인만 사용**한다. 타인과
  공유하거나 팀 계정처럼 돌려쓰지 않는다.
- 접속 자격증명을 코드 저장소, 공개 노트북, 채팅 로그 등에 평문으로 남기지
  않는다.

## 3. 인용 의무

이 데이터를 활용한 논문·보고서·발표 자료에는 아래와 같은 형태로 출처를
표기해야 한다 (문구는 상황에 맞게 조정 가능하나, 데이터 제공처와 제공
경위가 드러나야 한다):

> 본 연구는 [과제명]을 통해 제공받은 전력 발전·수급 데이터(남부발전,
> 남동발전, 전력거래소 SMP, 기상청 ASOS 등)를 활용하였다.

공동 연구·외부 공개 논문의 경우 사전에 데이터 제공 기관과 인용 표기
방식을 협의한다.

## 4. 감사 로그 고지

발급받은 role로 실행하는 **모든 SQL 쿼리는 서버 측에 감사 로그로
기록된다** (`log_statement=all`, 접속 시각·사용자·DB명 포함). 이는 접속
권한 발급 시 이미 적용돼 있으며 별도 동의 절차 없이 상시 작동한다. 문제가
발생하면 이 로그를 근거로 조사가 이루어질 수 있다는 점을 인지하고
사용한다.

감사 로그 보존 기간은 별도로 정해져 있지 않다 — 컨테이너 로그(`json-file`
드라이버)에 크기·기간 제한 없이 쌓이며, 별도 로그 로테이션이나 만료 정책을
운영하지 않는다.

## 5. 과제 종료 시 조치

- 과제가 종료되거나 연구원이 과제에서 이탈하면 **접속 권한(role)은
  회수된다.** 회수 이후에는 더 이상 접속할 수 없다.
- 로컬에 내려받은 원본 데이터, 중간 산출물, 백업 사본은 과제 종료 후
  **파기**한다. 논문·보고서에 포함된 요약 통계·그래프는 파기 대상이 아니다.
- 파기 확인이 필요한 경우 관리자의 요청에 따라 삭제 완료를 확인해 준다.

## 6. 데이터 한계에 대한 고지

이 데이터는 연구용으로 정리된 것이지 검증된 공식 통계가 아니다.
[데이터 카탈로그](04-data-catalog.md)에 정리된 품질 등급(`data_quality`), 좌표 신뢰도,
단위·시간 규약의 함정을 확인하지 않고 사용한 분석 결과에 대해 데이터
제공 측은 책임지지 않는다. 데이터의 한계를 인지하고 사용하는 것은
연구원의 책임이다.

## 7. 서약

아래에 동의함으로써 접속 권한을 발급받는다.

- [ ] 본 약관(1~6항)을 읽고 동의한다.
- [ ] 데이터를 본 과제 목적 외로 사용하지 않고, 재배포하지 않는다.
- [ ] 발급받은 자격증명을 본인만 사용한다.
- [ ] 모든 쿼리가 감사 로그로 기록됨을 인지한다.
- [ ] 과제 종료 시 접근 회수 및 사본 파기에 협조한다.
