# GIS-EnergyHub

태양광·풍력 발전량, 전력 시장 가격(SMP), 기상, 전력수요, 국제유가 에너지관련 데이터를 **한국어로 질문해서** 꺼내 쓰는 연구용 조회 서비스입니다. SQL을 몰라도 됩니다. 질문하면 AI가 조회 조건과 실행할 SQL을 보여 주고, SQL이 실행되어 결과 CSV다운로드와 결과표가 나옵니다.

{% hint style="info" %}
이 안내서는 누구나 읽을 수 있는 공개 문서입니다. 서비스 주소, 접속 키, 계정은 여기에 적지 않고 관리자가 신청한 분께 따로 전달합니다.
{% endhint %}

## 사용방법

1. **신청합니다**\
   이용·보안 서약을 제출하면 관리자가 확인합니다.
2. **연결합니다**\
   관리자가 보낸 1회용 키로 내 PC를 연구용 폐쇄망에 연결합니다.
3. **묻습니다**\
   웹 채팅에서 질문하고, 조건과 SQL을 확인해 결과를 받습니다.

처음이라면 [접속 준비하기](start/access.md)와 [첫 질문 해보기](start/first-query.md) 순서로 따라 하세요.

## 어떤 데이터가 들어 있나요

| 분야    | 들어 있는 것                                    |
| ----- | ------------------------------------------ |
| 발전량   | 발전소별 시간 단위 발전량 (태양광, 풍력 등)                 |
| SMP   | 전력 시장 가격 (하루전시장 시간별, 가중평균)                 |
| 기상 관측 | 기상청 관측소의 시간별·일별 관측값                        |
| 기상 예보 | 기상청 동네예보 (단기·초단기). 비어 있는 월은 수집을 요청할 수 있습니다 |
| 전력수요  | 전국·제주 계통 수급(5분 단위), 지역난방 열수요               |
| 국제유가  | 브렌트·WTI 시간별 시세                             |
| 송배전망  | 변전소·송전선로 위치와 한전 접속 여유용량                    |

기간, 단위, 시간은 데이터마다 다릅니다. 시간은 대부분 한국 시간(KST) 구간 시작이지만 기상 예보는 UTC입니다. 질문하기 전에 [데이터 카탈로그](04-data-catalog.md)에서 확인하세요.

## 보안설명

* **들어오는 길이 닫혀 있습니다.**\
  안내받은 서비스 주소는 관리자가 승인해 키를 발급한 기기에서만 열립니다.
* **읽기만 합니다.**\
  서비스는 읽기 전용 계정으로 `research` 스키마의 조회용 뷰만 읽습니다. 데이터를 고치거나 지울 수 없습니다.
* **실행된 SQL은 모두 기록됩니다.**\
  서버의 감사 로그에 남습니다.
* **질문과 결과 일부는 OpenAI로 전송됩니다.**\
  개인정보, 비밀번호, API 키, 공개가 금지된 연구 내용은 질문에 넣지 마세요.
* **키와 계정은 본인만 씁니다.**\
  과제가 끝나거나 연구에서 빠지면 접속 권한은 회수됩니다.

자세한 내용은 [LLM·MCP 데이터 처리와 투명성](06-llm-transparency.md)과 [이용조건 · 보안 서약](05-terms.md)에 있습니다.
