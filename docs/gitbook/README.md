# 한눈에 보기

발전량·SMP·기상·전력수요 데이터를 연구 목적으로 조회하는 경로와 서로 다른 보안
경계를 안내합니다.

{% hint style="info" %}
이 GitBook은 누구나 읽을 수 있는 공개 안내서입니다. 실제 주소, 계정, 비밀번호는
관리자가 별도 채널로 전달합니다.
{% endhint %}

## 어떤 방법을 사용할까요?

| 경로 | 추천 대상 | 접속·DB 경계 | 실행 전 승인 |
| --- | --- | --- | --- |
| 직접 SQL | 재현 가능한 분석·통계·그래프 | Tailscale 폐쇄망 + 개인별 읽기전용 role | 연구원이 SQL을 직접 실행 |
| 정식 호스팅 LLM·MCP | 설치 없는 자연어 탐색 | LibreChat 로그인 + 공용 읽기전용 role `demo_ro` | 조건과 SQL을 웹에서 1회 승인 |
| 레거시 로컬 stdio `run_sql` | 고급 사용자·호환 목적 | Tailscale 폐쇄망 + 개인별 읽기전용 role | 별도 승인 workflow 없음 |

정식 호스팅 경로와 직접 SQL·로컬 stdio 경로는 같은 신원·감사 경계를 쓰지
않습니다. 호스팅 서비스의 DB 감사 로그에는 공용 `demo_ro`가 기록됩니다. 현재는
LibreChat 계정 로그인과 30분짜리 승인 링크가 경계이며, Tailscale IP 허용 목록과
IP→`principal` 매핑은 후속 설계로 미뤄져 있습니다.

## 처음 한 번만 준비하세요

1. 이용조건을 읽고 서약합니다.
2. 정식 호스팅 서비스를 쓸 때는 관리자에게 LibreChat 주소와 계정을 받습니다.
3. 직접 SQL이나 레거시 로컬 stdio를 쓸 때는 Tailscale에 가입하고 개인 DB 계정을
   별도 채널로 받습니다. 실제 값을 문서나 채팅에 붙여넣지 마세요.
