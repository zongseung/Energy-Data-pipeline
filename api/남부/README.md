## 「급전속보」 계열은 신청하지 마라 (2026-09-10 판단)

**급전(給電)** 은 발전기에 출력을 지시하는 계통 운영이다 (急이 아니다).
**급전속보 = 그 운영 결과를 매일 한 장으로 정리한 브리핑**이다.

남부가 `급전속보` 로 6개를 내놓는데, **한 브리핑 문서의 여섯 페이지**로 보인다.
그래서 전부 같은 성격이다 — 하루 몇 행, **발전소 축 없음**, 회사·권역·연료 단위 집계.

실측으로 확인한 둘이 정확히 그랬다:

| 확인됨 | 실제 | 판정 |
|---|---|---|
| 기상현황 급전속보 | 8개 도시 일별 최저·최고기온 | ❌ ASOS 가 낫다 |
| 발전회사별 점유율 급전속보 | 발전 6사 하루 1행씩 | 🔸 검증 기준선으로만 |

**아직 안 한 4개도 같을 것으로 본다** — 발전실적 · 전력수급 · 연료현황 · 발전원별 점유율.
발전소별 시간별이 목표라면 축이 맞지 않는다.

유일한 재검토 후보는 **발전원별 점유율 급전속보**(`15125309`) 다.
태양광·풍력 비중이 나올 수 있어 `realtime-gen-mix-collection`(KPX 5분 발전원별)과
대조할 값어치는 있으나, 그쪽이 5분이라 이건 일별로 성기다.

## `_GW` 중복 문제 — 해결됨 (2026-09-10)

**같은 엔드포인트다.** `_GW` 는 새 API 가 아니라 데이터셋 등록만 다시 한 것이다.
시간대별 태양광발전실적의 `_GW` 본(`15125318`)을 신청받았더니 엔드포인트가
기존과 똑같은 `PwrSunLightInfo` 였다. **아무거나 신청하면 된다.**
