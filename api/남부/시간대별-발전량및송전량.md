## 키가 API 마다 다르다 (실측)

"키는 다 같다"는 가정은 틀렸다.

| | PwrSunLightInfo | PwrGenTran |
|---|---|---|
| `NAMBU_API_KEY` (88자) | ✓ | ✗ `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` |
| `NAMBU_PWRGENTRAN_KEY` (64자 hex) | ✓ (인증 통과) | ✓ |

새 키가 둘 다 통과하므로 **하나로 합칠 수 있어 보이나, 운영 수집기를 건드리는 일이라
아직 바꾸지 않았다.** 바꾸려면 `NAMBU_API_KEY` 를 새 키로 교체 → 남부 flow 재확인.

## 응답 항목

```
ymd  ipptnm  ins  hogigb  hogi

발전  qvodgen  qvodavg  qvodmax  qvodmin        qhorgen01 ~ qhorgen24
송전  qvodtrn  qvodtrnavg  qtrnmax  qtrnmin     qhortrn01 ~ qhortrn24
```

**`qhorgen`(발전) 과 `qhortrn`(송전) 두 벌**이 온다. PwrSunLightInfo 에는 송전이 없다.
송전 = 발전 − 소내소비. 하동#1 실측: 일 발전 10,305,192 / 송전 9,766,552 (약 94.8%).

**단위 kWh.** 하동#1 시간별 최대 508,141 → 508MW, 하동화력 1호기 정격 500MW 와 부합.

현재 남부는 태양광 18계열뿐이다.

## 함정

1. **`ins` 를 fuel_type 으로 그대로 쓰면 안 된다.** 연료전지·소수력·태양광 일부가
   `복합` 으로 분류돼 있다 (`신인천 연료전지 3단계`, `삼척소수력`,
   `신인천 1,2단계 주차장 태양광` 이 전부 `ins=복합`). `부산1400kWp발전소` 도 `복합` 인데
   이름은 태양광이다. **`hogigb`/`ipptnm` 을 같이 봐야 한다.**

2. **유일키는 `(ipptnm, hogigb, hogi)` 3개 조합이다.** 71/71 유일.
   `(ipptnm, hogi)` 는 69/71 로 부족하다.

3. **`hogi` 는 숫자가 아니다.** 화력·태양광은 `1`~`8`, 복합은 `CG1`~`CG8`(가스터빈) /
   `CS1`~`CS4`(증기터빈), 연료전지는 `FC2`·`FC3`·`FC5`. `hogigb` 는 CC 축 단위라 한 축에 GT 2기 + ST 1기가 묶인다.

   ```
   부산복합 / 부산복합CC#1 / CG1     ┐
   부산복합 / 부산복합CC#1 / CG2     ├ 한 축
   부산복합 / 부산복합CC#1 / CS1     ┘
   ```

   → **남동 화력이 이미 `분당화력_CG1`, `분당화력_CS1` 규약으로 들어가 있다.**
   남부도 같은 규약(`부산복합_CG1`)으로 가면 일관된다.

4. **표기 오류가 섞여 있다.** `삼척소수력` 의 `hogigb` 가 `삼척수소력` 이다.

5. **정지 중인 호기가 0 으로 온다** (영월복합 4기 전부 0, 부산복합 CC#3·#4 전부 0).
   NULL 이 아니라 0 이라 "발전 안 함" 과 "자료 없음" 이 구분되지 않는다.

## 발전소코드

참고자료 xlsx 가 준 `발전소코드 · 발전소명 · 호기코드 · 호기명칭` 69행은
**남부 전사 코드로 판단해 [발전소코드.md](발전소코드.md) 로 옮겼다** (xlsx 는 삭제).
우리 DB 와의 대조, 참고자료가 API 보다 낡은 지점도 거기 있다.

주의: 참고자료의 `호기코드` 는 CC 축 단위(`1CG`)이고 이 API 응답의 `hogi` 는
터빈 단위(`CG1`)라 **표기 순서가 다르다.** 직접 매칭하면 안 된다.

## 우리 스키마 매핑 (초안)

```
ipptnm + hogigb + hogi -> plants.plant_name   (규약: <발전소>_<hogi>, 남동 화력과 동일)
                       -> plants.operator = 'nambu'
ins + hogigb 조합      -> plants.fuel_type    (ins 단독 금지, 위 함정 1)
ymd + qhorgen01..24    -> generation(timestamp, plant_id, gen_kwh, source='api')
qhortrn01..24          -> 저장처 미정 — generation 에 송전 컬럼이 없다
```

**결정 필요**: 송전량(`qhortrn`)을 버릴지, `generation` 에 컬럼을 늘릴지, 별도 테이블로 뺄지.
