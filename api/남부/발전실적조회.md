## 요청 파라미터

PwrGenTran 과 같다. `serviceKey` · `pageNo` · `numOfRows` · `strSdate` · `strEdate` (YYYYMMDD).
필터 없이 하루 71건이 온다.

## 응답 항목

```
ymd  ipptnm  ins  hogigb  hogi
qcapdes  qcapdes24  qvodgen  qvodtrn
```

- `qcapdes` — **설비용량 kW.** 하동#1 = 500,000 (=500MW, 정격과 일치)
- `qcapdes24` — `qcapdes × 24`. 71계열 전부 정확히 24배다. **파생값이라 저장할 필요 없다**
- `qvodgen` / `qvodtrn` — 일 발전량 / 일 송전량 kWh

## 우리 스키마 매핑

**`plants.capacity_mw` 채우기 전용.** `generation` 에는 넣지 않는다.

```
qcapdes / 1000 -> plants.capacity_mw
               -> plants.capacity_confidence = '확실' (발전사 공시값)
```

계열 식별은 [발전소코드.md](발전소코드.md) 를 거친다. 현재 남부 태양광은
`capacity_mw` 가 비었거나 `capacity_confidence='불확실'` 인 게 많다.
