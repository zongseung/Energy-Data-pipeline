## 1. 서버 오류로 아무것도 못 받는다

파라미터를 무엇으로 주든 HTTP 200 에 오류 본문이 온다 (2026-09-10 실측).

```
<Error><code>999</code><message>
### Error querying database.  Cause: java.sql.SQLSyntaxErrorException:
    ORA-00904: "SMP_JUJU": 부적합한 식별자
```

남부 쪽 쿼리가 존재하지 않는 컬럼을 참조한다 — `SMP_JUJU` 를 `SMPJEJU` 로 별칭 지었는데
원본 컬럼명이 틀렸다. **우리 쪽에서 고칠 수 있는 게 없다.** 남부가 고쳐야 한다.

## 2. 고쳐져도 안 쓴다 — SMP 는 KPX 에서 받고 있다

오류 메시지가 노출한 쿼리로 제공 항목은 알 수 있다.

```
TRADE_DT (거래일)  TRADE_HR (거래시)  BID_CAP (입찰량)
SMP  SMP_JEJU (제주 SMP)  QTHA  QTHB  QTHC  MTAVG (월평균)
```

SMP 시간별이다. 우리는 이미 KPX 에서 직접 받는다 —
`pipeline/fetch_data/smp/`, `daily-smp-collection`(매일 09:00) ·
`daily-smp-realtime-jeju`(매일 19:00) · `monthly-smp-aggregate`.
KPX 가 원천이고 이쪽은 재공개다. **원천을 두고 재공개를 받을 이유가 없다.**
