## 왜 안 쓰나

전국 8개 **도시** 의 **일별 최저·최고 기온과 날씨 문구**다. 발전소 위치가 아니다.

```
권역: 인천 원주 수원 광주 부산 대전 대구 서울   (하루 8행, 2016~ 현재 완전)
```

우리 ASOS 는 **41지점 · 시간별 · 일사량 포함**이다. 이건 8지점 · 일별 · 기온만이다.
정보량이 모든 축에서 적다.

유일한 차별점은 `tstat`/`tmintemp`/`tmaxtemp` 가 **당일 예보**라는 것인데,
동네예보는 이미 따로 받고 있다.

## 응답 항목

```
tradedt  zonenm  ystat  ymintemp  ymaxtemp  tstat  tmintemp  tmaxtemp  inputdt
```

`y*` = 전일 실적, `t*` = 당일 예보. `ystat`/`tstat` 는 `맑음`·`구름많음` 같은 문구.
`inputdt` 는 값이 `system` 이다 (날짜가 아니다).

2026-08-03 인천: `ystat=맑음 ymintemp=27.1 ymaxtemp=33 / tstat=맑음 tmintemp=26 tmaxtemp=34`
