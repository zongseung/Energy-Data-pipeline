## 왜 값어치가 있나 — 우리 데이터가 얼마나 빠졌는지 잴 수 있다

발전소 축이 없어 `generation` 에는 못 들어간다. 그런데 **발전 6사를 같은 기준으로
한 줄씩 주는 자료는 여기뿐**이다.

우리는 남동·중부·남부·동서를 각각 다른 원천에서 모으고 있고, 각각 몇 계열이 빠졌는지
알 방법이 없었다. 이걸 분모로 쓰면 잰다.

```
우리 남동 발전량 합계  ÷  genqt(남동)   = 우리가 확보한 비율
```

빠진 계열이 있으면 비율이 1 보다 작게 나온다. **[발전량 전수 현황 보고서]의
"미검증 41계열" 같은 구멍을 수치로 잡을 수 있다.**

## 응답 항목

```
tradedt  compcd  compnm  faccap  facrate  supcap  suprate  genqt  genrate  avgpower  avgrate
```

| 항목 | 뜻 | 주의 |
|---|---|---|
| `compcd` | 발전사 코드 | `01`~`06`, `99`=기타 |
| `compnm` | 발전사명 | **`한   수   원` 처럼 공백이 끼어 있다.** 파싱 시 공백 제거 필요 |
| `faccap` | 설비용량 | **`31,345` 처럼 천단위 콤마가 들어온다.** 숫자 변환 전 제거 필요 |
| `facrate` | 설비 점유율 % | |
| `supcap` | 공급능력 | |
| `suprate` | 공급능력 점유율 % | |
| `genqt` | 발전량 | **단위 미확인** (남부 6,971 vs 우리 계산 일 137,329 MWh / 평균출력 5,722 MW) |

## 우리 스키마 매핑

발전소 축이 없다. `generation` 에 안 들어간다.
**검증용 스크립트에서 직접 조회해 쓰는 것이 맞다.** 저장한다면 별도 집계 테이블.
