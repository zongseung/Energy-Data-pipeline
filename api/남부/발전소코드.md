# 남부 발전소·호기 코드

**남부 전사 코드로 판단한다 — API 전용이 아니다.**

- `997D` 가 [시간대별 태양광발전실적](시간대별-태양광발전실적.md) 의 `strOrgCd`(= `plants.plant_code`) 이면서
  [시간대별 발전량및송전량](시간대별-발전량및송전량.md) 참고자료의 발전소코드다. **두 API 가 이미 같은 코드를 쓴다.**
- 코드가 설비 계통을 따라간다: 하동화력 `8621`~`8628` 8기 연번, 부산복합
  `8941`~`8948`(GT) + `8949`·`894A`~`894C`(ST), 신인천복합 `8759`·`875A`~`875G`(GT) +
  `875T`~`875W`(ST). 발전본부·연료별로 대역을 갈라 쓰고 GT/ST 까지 구획이 나뉜다.
  API 가 자체 생성한 ID 라면 이런 구조가 나올 이유가 없다 — 사내 설비마스터로 본다.

→ **다음 API 도 이 코드로 조회할 가능성이 높다.** 단, 확인된 건 위 2개뿐이니
승인되는 API 마다 대조할 것.

출처: `한국남부발전(주)_시간대별 발전량및송전량 정보조회_참고자료(발전소,호기 코드).xlsx`
(PwrGenTran 활용신청 시 제공, 69행). 내용을 아래로 옮기고 원본 xlsx 는 삭제했다.

## 참고자료는 API 보다 낡았다

| | 참고자료 (69행) | PwrGenTran 실응답 (71계열) |
|---|---|---|
| 신세종복합 | 발전소명이 `#1 GT` / `#1 ST` 로 깨짐 (`7286`/`7287`) | `신세종복합 #1 GT` / `#1 ST` 정상 |
| 신인천 연료전지 | **1단계** 1기 (`997U`) | **2·3·5단계** 3기 |

→ **코드↔이름은 참고자료, 현행 계열 목록은 API 를 정본으로 삼는다.**

## 우리 DB 와의 대조

남부 18계열 중 **10개만** 참고자료에 있다. 안 맞는 8개는 두 부류다.

**① 종료된 계열** — 참고자료가 현행 설비만 담은 듯하다.
`9979` 이천D(2023-04-24 종료) · `997G` 부산신항(2023-11-04) · `9987` 부산역 선상 주차장(2023-10-19)

**② `plant_code` 가 가짜다**

```
plant_id 14, 15    -> plant_code = B997   (둘 다 같은 코드, 부산본부)
plant_id 16,17,18  -> plant_code = S997   (셋 다 같은 코드, 삼척소내)
```

`B997`/`S997` 은 참고자료에 없다. 실제 코드는 따로 있다 —
부산복합태양광 `9976`/`997Z`, 삼척소내태양광 `997T`/`997O`/`997X`/`9980`.
**`plant_code` 단독은 유일키가 아니다.** 지금도 `(plant_code, unit_no)` 로 써야 한다. 정리 대상.

**③ `plant_id=7` 은 이름이 틀렸을 수 있다.**
우리는 `한국남부발전(주)_부산운동장 태양광발전실적` 인데 같은 코드 `997R` 이
참고자료·API 모두 **`부산1400kWp발전소`** 이고 API 연료구분도 `복합` 이다.

**④ 참고자료에 있고 우리에 없는 태양광 7계열**
`9976` 부산복합태양광 · `997Z` 부산복합태양광2단계 · `997T` 삼척그린파워태양광 ·
`997O` 삼척소내태양광#2 · `997X` 삼척소내태양광#3 · `9980` 삼척소내태양광#4 ·
`B105` 신인천 본관주차장 태양광
