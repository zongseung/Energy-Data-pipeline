## 동작은 하는데 해석이 안 된다

하루 1행. 2016~현재. (2026-01-01 은 0건 — 결측이 있다.)

```
tradedt  poa  pra  apra  amgo  pse  mgo  eoso  xeoga
```

2026-08-03: `poa=244675 pra=244533 apra=244532.347927 amgo=124605.120423
pse=0 mgo=124605.120423 eoso=0 xeoga=0`

관찰한 것만:

- `pra` 는 `apra` 의 반올림값이다 (244533 ← 244532.347927)
- `mgo` 와 `amgo` 는 3일 내내 완전히 같았다
- `pse` · `eoso` · `xeoga` 는 3일 내내 0
- `poa`/`pra` 는 24만대, `amgo` 는 8.9만~12.5만 사이에서 움직인다

**단위도 뜻도 모른다.** 남부 일 발전량(137,329 MWh)이나 설비용량(12,009 MW) 어느 쪽과도
안 맞아 무엇의 양인지 특정하지 못했다. 참고문서 없이는 추측일 뿐이다.

## 안 쓰는 이유

해석이 되더라도 전력거래·SMP 는 **KPX 에서 직접 받는 것이 정본**이다
(`pipeline/fetch_data/smp/`, `daily-smp-collection` 외 3개 flow).
발전사가 재공개하는 값을 받을 이유가 없다.

참고문서를 구하면 재검토할 것.
