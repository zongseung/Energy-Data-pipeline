## 받는 방법

포털 파일데이터는 인증이 없다.

```
① https://www.data.go.kr/data/{pk}/fileData.do  HTML 에서  atchFileId=FILE_\d+  추출
② https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=<ID>&fileDetailSn=1
③ 원본 CP949 → UTF-8 로 변환해 저장
```

```bash
uv run python -m pipeline.fetch_data.nambu.file_download            # 25종 전부 (약 2초)
uv run python -m pipeline.fetch_data.nambu.file_download 15043410   # 하나만
```

## 스키마

23종이 같은 모양이다. **API `PwrSunLightInfo`/`PwrGenTran` 과 1:1 대응한다.**

```
년월일 · 호기 · 총량 · 평균 · 최대 · 최소 · 최대(시간별) · 최소(시간별) · 1 ~ 24
  ↕        ↕      ↕       ↕       ↕      ↕          ↕             ↕          ↕
ymd    hogi  qvodgen qvodavg qvodmax qvodmin  qvodtimemax  qvodtimemin  qhorgen01~24
```

**단, 발전소명 컬럼이 없다.** 파일명이 곧 발전소다. 발전소코드(`gencd`)도 없어
[발전소코드.md](발전소코드.md) 를 거쳐 이어야 한다.

## 파일 ↔ API 역할 분담

```
2013-01-01 ─────────────────────── 2026-02-28        파일 (연 1회, 한 번에 13년치)
                        2015-10-23 ──────────────────────── 현재   API (매일)
                                   └── 겹치는 구간에서 값 대조 → 이어붙일 지점 확정
```

- **과거는 파일** — 2013~2015 는 API 에 아예 없다
- **2026-03 이후는 API** — 파일이 거기서 끊긴다 (풍력만 2026-03-31)
- **겹치는 구간**은 같은 날 같은 값인지 대조한다. 다르면 어느 쪽이 정본인지 정해야 한다
