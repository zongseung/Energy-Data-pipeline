# api/

공공데이터포털 오픈API 의 **연결 정보와 참고문서 정리본**을 모아둔다.
수집 코드는 여기 없다 — 코드는 `pipeline/fetch_data/` 다.

## 진행 방식 (2026-09-10 합의)

1. **파일데이터를 먼저 깐다.** 발전소별 실적 CSV 가 API 보다 기간이 길고 공백이 적을
   수 있다. 파일로 바닥을 만들고 그 위에 API 를 얹는다.
2. **API 는 연결만 해둔다.** 신청 → 승인 → 이 폴더에 문서 한 장. **지금은 실수집 안 한다.**
3. 참고문서(스펙 xlsx/pdf)가 오면 읽고 요약해서 해당 API 문서에 박는다.
   문서가 없는 API 는 `참고문서: 없음` 으로 두고 실측으로 채운다.

## 폴더

발전사별로 나눈다. 폴더명은 한글 약칭이다.

| 폴더 | 발전사 | 영문 | DB `operator` | 기관코드 |
|---|---|---|---|---|
| `남부/` | 한국남부발전 | Nambu | `nambu` | B552520 |
| (예정) `남동/` | 한국남동발전 | Namdong | `namdong` | — |
| (예정) `동서/` | 한국동서발전 | Dongseo | `ewp` | — |
| (예정) `중부/` | 한국중부발전 | Jungbu | `komipo` | B552521 |

DB `plants.operator` 값은 `ewp`·`komipo` 로 들어가 있어 폴더명과 다르다. 위 표가 대응표다.

## 공통 규약

- **엔드포인트 형태**: `https://apis.data.go.kr/<기관코드>/<서비스명>/getDataService`
  - 단, 일부는 발전사 자체 포털로 간다 (남부 `dataopen.kospo.co.kr`). API 별 문서에 적는다.
- **키는 API 마다 다를 수 있다.** 같은 기관이라도 활용신청이 API 별로 따로고,
  포털이 신청 건마다 다른 키를 줄 때가 있다 (남부 실측: `NAMBU_API_KEY` 는
  PwrGenTran 에서 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`). **API 별로 키 변수를 따로 둔다.**
- 승인 안 된 API 는 HTTP 403 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`.
- **경로 끝에 `/getDataService` 가 필요하다.** 빼면 HTTP 400 `NO_OPENAPI_SERVICE_ERROR`.
- **한 기관이 준다고 그 기관 데이터인 건 아니다.** 남부 `GenPwrSupply` 는 전국 231계열이다.
- **키 인코딩 함정**: 디코딩된 키(`%` 없음)를 URL 문자열에 직접 박으면 `+` `/` `=` 가
  깨져 위 오류가 난다. `params=` 로 넘겨 라이브러리가 인코딩하게 할 것.

## 파일 규칙

- **파일을 만들기 전에 왜 만드는지 말한다.**
- 참고문서(xlsx/pdf)가 오면 **내용을 md 로 옮기고 원본은 지운다.** 원본을 남기지 않는다.
- 내용이 특정 API 에만 해당하면 그 API 의 md 안에 넣는다.
  **여러 API 가 공유하는 것만** 발전사 폴더 레벨로 올린다 (예: `남부/발전소코드.md`).
- 중간 산출물(csv 등)은 만들지 않는다. 원본에서 다시 뽑으면 되는 건 파일로 남기지 않는다.

## API 문서 한 장에 들어갈 것

파일명은 **한국어 API 명**으로 한다 (`시간대별-발전량및송전량.md`). 공백은 `-` 로.
GitBook 데이터 카탈로그로 그대로 옮길 것이라 사람이 읽는 이름이 우선이다.
엔드포인트 서비스명은 문서 첫 표에 적어 두면 `grep` 으로 역추적된다.

```
제목
**쓸모** ← 맨 위. 아래 셋 중 하나로 단정한다
    ✅ 정본     이 데이터는 여기서 받는다
    🔸 보조     제한적으로만 쓴다 (특정 컬럼만, 검증용만)
    ❌ 쓸모없음  받을 이유가 없다. 왜인지 한 줄 남긴다
데이터셋번호·링크 / 엔드포인트 / 신청상태 / 참고문서 / 중복후보
## 요청 파라미터
## 응답 항목
## 주기·범위·단위
## 우리 스키마 매핑      ← plants.plant_name·operator·fuel_type 와 어떻게 잇는지
## 미확인               ← 모르는 건 모른다고 남긴다
```
