## 상명풍력 파일은 송전량이다 (2026-10-21 확인)

데이터셋 설명 원문: *"발전시간별 컬럼은 송전량(kWh)를 단위로 합니다."*
컬럼 정의는 *"N시 송전량(MWh)입니다"* — **설명과 컬럼이 단위를 다르게 적어 모순이다.**
실측 최대 20,109,158 이고 상명풍력이 21MW 라 **Wh 로 보인다**(20.1MWh).

→ `renewEnergy` 의 `daypower`(발전량)와 이 파일을 대조하면 **최선이 상관 0.637**(오프셋 -1h)로
맞지 않는다. 같은 양이 아니기 때문이다. 시각 규약을 이 파일로 판정하려던 시도는 무효다.

**시간 표기도 불명**이다 — 컬럼이 `1시`~`24시`(코드 `1HOUR`~`24HOUR`)인데 `1시`가
00:00~01:00 인지 01:00~02:00 인지 페이지에 없다.

## renewEnergy 값은 발전량이고 공식과 일치한다

호기 단위로 1:1 대조되는 **소수력**으로 검증했다 (일 합계 기준):

| 공식 (15139102) | parquet | 양쪽>0 일수 | 비율 중앙값 | 사분위 |
|---|---|---|---|---|
| 보령소수력 1호기 | 보령 제1소수력 | 789 | **0.983** | 0.967~0.993 |
| 보령소수력 2호기 | 보령 제2소수력 | 561 | **0.992** | 0.981~1.003 |
| 신보령소수력 1호기 | 신보령 제1소수력 | 509 | 0.935 | 0.464~0.976 |

→ **일별 합계는 공식과 사실상 같다.** 신보령 1호기의 사분위가 넓은 건 따로 볼 일이다.

태양광은 공식이 **발전소 단위**라 1:1 이 안 된다 — 묶음을 맞추면 0.98~1.04,
안 맞으면 0.53~1.11 로 벌어진다 (신보령태양광 0.530 은 2호기가 전구간 0 이라 제외한 탓).
그래서 **"중부가 공식보다 9% 크다"는 판단은 틀렸다** — 묶음 오류였다.

## 미확인 / 다음

- `renewEnergy` 의 `daypower` 가 구간시작인지 구간종료인지 **미확정**. 판정에 쓸 시간별
  공식 자료가 송전량뿐이라 막혔다. 일별은 맞으니 일 단위 분석은 안전하다.
- 기관 전수 조사는 못 했다 — data.go.kr 기관 검색 페이지가 JS 렌더링이라 스크래핑이 10건에서 멈춘다.
  키워드 검색으로 찾은 것만 위에 적었다. **오픈API 는 `renewEnergy` 외에 발전량 계열이 안 보인다.**
- `plants.capacity_mw` 는 비어 있다. 소수력은 15139102 가 호기 단위라 바로 채울 수 있고,
  태양광은 발전소 단위라 호기로 쪼갤 근거가 없다. 연료전지·풍력은 자료를 더 찾아야 한다.
